# 江湖志 - 游戏说明

## 一、游戏简介

《江湖志》是一款基于 Godot 4.6 引擎开发的 2D 武侠角色扮演游戏。你将扮演一位初入江湖的侠客，在广袤的武侠世界中探索、修炼、战斗、结交豪杰，书写属于自己的江湖传奇。

## 三、核心系统

### 3.1 生存系统

角色拥有以下生存属性，需要持续关注：

- **饥饿值**：持续下降，低于20时体力加速消耗。通过食物（肉包子等）恢复。
- **体力值**：冲刺消耗，饥饿或受伤时恢复减慢。充足饥饿和健康时自然恢复。
- **伤势（气血）**：降至0时触发死亡机制。通过药品（金创药、大还丹等）恢复。
- **中毒值**：高于50时持续损失气血。自然缓慢消退，解毒散可快速清除。
- **内力**：攻击、格挡、闪避消耗。打坐修炼可恢复。

### 3.2 战斗系统

#### 攻击与连招
- **轻攻击**（鼠标左键）：消耗少量内力，出手快
- **重攻击**（鼠标右键）：消耗较多内力，伤害高
- **连招**：在连招窗口（0.5秒）内连续攻击可触发连招加成，伤害递增

#### 架势与破绽
- 三种架势各有优劣，合理切换是战斗关键
- **破绽值**：被攻击时增加，攻击架势被命中增加更多
- 破绽值达到80时进入**大硬直**状态（1.2秒无法行动）
- 破绽值会自然衰减

#### 格挡反击
- 格挡状态下被攻击会开启**反击窗口**（0.4秒）
- 在窗口内按Q+轻攻击可触发**格挡反击**，伤害x2，减少自身破绽30点

### 3.3 内功修炼

游戏包含6种内功心法，各有五行属性：

| 内功 | 五行 | 推荐修炼地 |
|------|------|-----------|
| 土灵归元诀 | 土 | 洞窟 |
| 寒冰真气 | 水 | 寒潭 |
| 烈阳心经 | 火 | 火山 |
| 玄阴鬼录 | 水 | 墓地 |
| 金刚不坏体 | 金 | 山巅 |
| 青木长生功 | 木 | 竹林 |

- 在匹配的环境中修炼速度x2
- **五行相克**：金克木、木克土、土克水、水克火、火克金。在相克环境中修炼效率降低70%，且内力受损
- 修炼圆满后获得内力加成

### 3.4 门派系统

#### 八大门派

| 门派 | 阵营 | 领地 | 声望要求 |
|------|------|------|---------|
| 少林寺 | 正派 | 少室山 | 2000 |
| 武当派 | 正派 | 武当山 | 1800 |
| 峨眉派 | 正派 | 峨眉山 | 1200 |
| 丐帮 | 正派 | 洛阳 | 800 |
| 日月教 | 邪派 | 黑木崖 | 1500 |
| 五毒教 | 邪派 | 苗疆 | 600 |
| 华山派 | 中立 | 华山 | 900 |
| 逍遥派 | 中立 | 灵鹫宫 | 1000 |

#### 门派晋升
通过贡献值晋升门派等级：弟子 → 内门弟子 → 执事 → 长老 → 副掌门 → 掌门

贡献阈值：0 / 100 / 300 / 800 / 2000 / 5000

#### 门派外交
- 正派门派之间自动结盟，与邪派为敌
- 门派之间可能发生吞并或解散

### 3.5 商店与交易系统

- 商店提供13种商品，涵盖武器、防具、药品、材料、饰品
- **供求定价**：供应充足时价格降低，需求旺盛时价格上涨
- **声望折扣**：声望越高，买入价格越低（最高30%折扣）
- 卖出价格为买入价格的50%
- 商店会定期补货

#### 物品稀有度

| 稀有度 | 颜色 | 最大库存 |
|--------|------|---------|
| 凡品 | 白色 | 20 |
| 良品 | 绿色 | 10 |
| 稀有 | 蓝色 | 5 |
| 史诗 | 紫色 | - |
| 传说 | 金色 | - |

### 3.7 死亡与传承

气血归零时触发死亡，根据正邪值和声望决定结局：

| 结局 | 条件 | 效果 |
|------|------|------|
| 被救 | 正派+高声望 | 恢复部分气血，损失20%铜钱 |
| 囚禁 | 邪派+低声望 | 损失40%铜钱和声望，关押30秒 |
| 传承 | 其他情况 | 以传人身份继续，继承50%武学和30%铜钱 |

### 3.8 奇遇系统

游戏中会随机触发10种奇遇事件，包括：
- 悬崖秘洞、高人传功、市井斗殴、神秘商人
- 毒蛇袭击、河畔渔翁、荒庙夜宿、酒馆斗酒
- 古墓奇遇、侠侣相遇

每个奇遇有2-3个选项，不同选择影响金钱、内力、道德、声望等属性。

### 3.9 誓约系统

可以立下誓言追求目标：
1. 成为天下第一
2. 富甲一方
3. 灭掉魔教
4. 博学多才
5. 行侠仗义
6. 自定义目标

誓言有进度追踪和里程碑系统。

### 3.10 NPC系统

- 4位固定NPC：谢云鹤（儒雅）、铁三娘（豪爽）、柳如烟（阴沉）、老樵夫（慈悲）
- NPC有日程系统：行走、工作、休息
- 可与NPC交谈、送礼、切磋、观察、邀请入住
- 好感度系统影响NPC对话和交互

## 四、环境与天气

### 环境区域
- **寒潭**：水属性，适合修炼寒冰真气
- **竹林**：木属性，适合修炼青木长生功
- **山巅**：金属性，适合修炼金刚不坏体

### 天气系统
- 下雨/下雪时NPC移动速度降低40%
- 天气影响部分奇遇触发条件

## 六、游戏技巧

1. **战斗**：善用架势切换，攻击架势输出高但容易被破防，防御架势适合等待反击时机
2. **修炼**：找对环境修炼事半功倍，避开五行相克的环境
3. **经济**：声望越高买东西越便宜，多做任务提升声望
4. **建造**：优先建农田解决饥饿问题，再建练功房加速修炼
5. **门派**：加入门派可习得独门武学，但叛离会损失声望
6. **生存**：随时关注饥饿值，饥饿会加速体力消耗形成恶性循环
7. **传承**：如果死亡不可避免，传承模式可以保留部分进度重新开始
