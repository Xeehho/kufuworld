# 江湖志

> 一款基于 Godot 4.6 的 2D 武侠 RPG，程序化生成大地图，像素风（参考星露谷物语/江湖风云传）。

你扮演一位初入江湖的侠客，在随机生成的广袤世界中探索、修炼、战斗、结交豪杰、加入门派、触发奇遇，书写属于自己的江湖传奇。

---

## 一、快速开始

### 环境要求

- Godot 4.6+
- 推荐分辨率：1920×1080（拉伸模式 canvas_items）

### 运行方式

1. 用 Godot 编辑器打开项目目录
2. 首次运行自动生成全部纹理、瓦片集、精灵帧（约需数秒）
3. 点击运行或按 F5 启动游戏

### 项目结构

```
my-godot-project/
├── scenes/               # 场景文件
│   ├── main.tscn         # 主场景（游戏入口）
│   ├── npc.tscn          # NPC角色模板
│   ├── dialog_box.tscn   # 对话框UI
│   └── star.tscn         # 星星收集小游戏
├── scripts/              # 核心脚本（35个）
│   ├── Main.gd           # 主入口，初始化所有子系统
│   ├── player.gd         # 玩家控制器（状态机/战斗/建造）
│   ├── npc_character.gd  # NPC角色逻辑
│   ├── world_generator.gd # 程序化世界生成（可达性洪泛/多格建筑）
│   ├── game_manager.gd   # 全局管理器（Autoload）
│   ├── texture_generator.gd # 像素风纹理生成器
│   ├── ui_theme.gd       # 统一武侠风UI主题
│   ├── tileset_generator.gd # TileSet 内存构建
│   └── ...               # 战斗/门派/商店/任务/奇遇等系统
├── resources/            # 游戏数据资源（.tres）
│   ├── skills/           # 18种武学技能
│   ├── inner/            # 6种内功心法
│   ├── clans/            # 8大门派
│   └── combo_tree.tres   # 连招树
├── sprites/              # 精灵图资源（首次运行自动生成）
│   ├── player/           # 玩家帧动画（72张PNG，4方向×4动作）

└── project.godot         # 项目配置
```

## 三、核心系统

### 3.1 生存系统

角色拥有以下属性，需要持续关注：

- **饥饿值**：持续下降，低于 20 时体力加速消耗。通过食物恢复。
- **体力值**：冲刺消耗，饥饿或受伤时恢复减慢。
- **气血**：归零触发死亡机制。通过药品恢复。
- **中毒值**：高于 50 时持续损失气血。解毒散可快速清除。
- **内力**：攻击、格挡、闪避消耗。打坐修炼可恢复。

### 3.2 战斗系统

#### 攻击与连招
- **轻攻击**（鼠标左键）：消耗少量内力，出手快
- **重攻击**（鼠标右键）：消耗较多内力，伤害高
- **连招**：0.5 秒连击窗口内连续攻击触发连招加成，伤害递增
- **打击反馈**：扇形刀光特效 + 命中粒子飞散 + 伤害飘字 + 相机震动

#### 架势与破绽
- 三种架势各有优劣，合理切换是关键
- 破绽值被攻击时增加，攻击架势被命中增加更多
- 破绽值达到 80 时进入**大硬直**（1.2 秒无法行动）
- 破绽值会自然衰减

#### 格挡反击
- 格挡状态下被攻击开启**反击窗口**（0.4 秒）
- 窗口内按 Q + 轻攻击触发**格挡反击**，伤害 x2，减少自身破绽 30 点

### 3.3 内功修炼

6 种内功心法，各有五行属性：

| 内功 | 五行 | 推荐修炼地 | 内力加成 |
|------|------|-----------|---------|
| 土灵归元诀 | 土 | 洞窟 | 18 |
| 寒冰真气 | 水 | 寒潭 | 15 |
| 烈阳心经 | 火 | 火山 | 12 |
| 玄阴鬼录 | 水 | 墓地 | 5 |
| 金刚不坏体 | 金 | 山巅 | 25 |
| 青木长生功 | 木 | 竹林 | 20 |

- 匹配环境修炼速度 x2
- **五行相克**：金克木、木克土、土克水、水克火、火克金。相克环境修炼效率降低 70%，内力受损

### 3.4 武学技能

6 类武器 × 3 阶段（起手/连击/终结）= 18 种技能：

| 类别 | 起手 | 连击 | 终结 |
|------|------|------|------|
| 拳掌 | 直拳 | 崩拳 | 破山拳 |
| 剑法 | 点苍 | 流云剑 | 万剑归宗 |
| 刀法 | 横斩 | 回旋斩 | 裂地斩 |
| 棍法 | 扫堂棍 | 挑云棍 | 霸王棍 |
| 暗器 | 飞蝗石 | 金钱镖 | 暴雨梨花 |
| 内功 | 吐纳术 | 护体罡气 | 真气爆发 |

### 3.5 门派系统

#### 八大门派

| 门派 | 阵营 | 领地 | 声望要求 |
|------|------|------|---------|
| 少林寺 | 正派 | 少室山 | 2000 |
| 武当派 | 正派 | 武当山 | 1800 |
| 峨眉派 | 正派 | 峨眉山 | 1200 |
| 丐帮 | 正派 | 洛阳 | 800 |
| 日月教 | 邪派 | 黑木崖 | 1500 |
| 五毒教 | 邪派 | 苗疆 | 600 |
| 华山派 | 中立 | 华山 | 900 |
| 逍遥派 | 中立 | 灵鹫宫 | 1000 |

#### 门派交互
- 进入门派领地后右上角出现「⛩ 门派」按钮（闪烁提示）
- 交互面板：拜入门下、请安问好（贡献+5）、切磋赐教、背叛师门
- 通过贡献值晋升：弟子 → 内门弟子 → 执事 → 长老 → 副掌门 → 掌门
- 贡献阈值：0 / 100 / 300 / 800 / 2000 / 5000

#### 门派外交
- 正派之间自动结盟，与邪派为敌
- 门派之间可能发生吞并或解散
- 门派经济/外交/战争 tick 实时模拟

### 3.6 商店系统

- 13 种商品：武器、防具、药品、材料、饰品
- **供求定价**：供应充足降价，需求旺盛涨价
- **声望折扣**：声望越高买入价越低（最高 30%）
- 卖出价为买入价的 50%
- 定期补货

### 3.7 建造系统

| 建筑 | 花费 | 尺寸 | 功能 |
|------|------|------|------|
| 茅屋 | 15木 5石 | 3x2 | 住所，可邀请NPC入住 |
| 练功房 | 20木 15石 | 2x2 | 修炼加速 |
| 炼丹房 | 15木 20石 | 2x2 | 炼丹 |
| 农田 | 5木 2石 | 2x2 | 提供食物 |
| 围墙 | 3木 8石 | 1x1 | 防御 |

### 3.8 奇遇系统

随机触发 20 种奇遇事件，包括：悬崖秘洞、高人传功、市井斗殴、神秘商人、毒蛇袭击、河畔渔翁、荒庙夜宿、酒馆斗酒、古墓奇遇、侠侣相遇、山贼拦路、比武招亲、瘟疫村庄、黑市交易等。

每个奇遇 2-3 个选项，影响金钱、内力、道德、声望等属性。结算面板内展示结果文本 + 得失明细（绿得红失），"继续"按钮关闭。

### 3.9 誓约系统

立下誓言追求目标，同时只能持有一个誓言：

1. 成为天下第一
2. 富甲一方
3. 灭掉魔教
4. 博学多才
5. 行侠仗义

立新誓自动放弃旧誓。有进度追踪和里程碑系统。

### 3.10 死亡与传承

气血归零触发死亡，根据正邪值和声望决定结局：

| 结局 | 条件 | 效果 |
|------|------|------|
| 被救 | 正派+高声望 | 恢复部分气血，损失 20% 铜钱 |
| 囚禁 | 邪派+低声望 | 损失 40% 铜钱和声望，关押 30 秒 |
| 传承 | 其他情况 | 以传人身份继承 50% 武学和 30% 铜钱 |

### 3.11 任务系统

- 动态生成任务：除恶、护送、寻宝等
- 多个任务可同时接取
- 任务日志 HUD 实时显示进度

### 3.12 NPC 系统

- 12 位 NPC 分布全图（含少林慧空、武当清虚、江南沈万等）
- 5 种外观：武者、书生、商人、长者、神秘人
- 日程系统：行走、工作、休息
- 交互：交谈、送礼、切磋、观察、邀请入住
- 好感度系统影响交互内容
- **出生点可达性保障**：所有 NPC 自动生成在玩家可到达的瓦片上，不可达自动搬迁

### 多格建筑

2/3/4/5 格宽中式建筑（瓦片 ID 19-32），由城镇布局自动选取：

- 贯通式屋顶：正脊贯穿全宽，仅两端山墙收口，拼接后为一座完整大宅
- 大门楼在中心格，两侧格为槛窗长廊
- 大宅（4/5 格）有重檐 + 朱柱 + 金质鸱吻 + 红灯笼
- 城镇内部优先放置多格建筑，剩余空格填充单格房/茅屋/院子

### 地图生成特性

- **安全出生点**：从地图中心向外稠密扫描，搬迁到 7×7 全可通行区域（连通性 BFS 校验 ≥200 瓦片）
- **可达性洪泛**：以出生点为源 BFS 标记所有可通行瓦片（实测约 14000+ 格），城镇/POI/NPC 选址必须落在可达区内
- **河流**：3-4 条正弦曲线河流，宽度 3-5 格，每隔 15 格有桥
- **城镇**：4-6 个随机城镇，栅栏围合 + 十字路口留门 + 多格建筑 + 农田
- **POI**：6 种类型（城镇/门派/洞穴/修炼场/遗迹/集市），去硬编码坐标，地形条件 + 可达性双重校验
- **围合地形留门**：城镇/门派栅栏圈在十字方向留门铺路，洞穴南侧留草地通道

```
+----------------------------------------------------------+
| [生存状态]  [时辰·天气]     [奇遇|立誓|门派]  [事件流]   |
```

### 统一主题

所有 HUD/弹窗使用 `UITheme` 静态方法获取样式（墨色底 + 描金边 + 圆角 + 投影），禁止散落硬编码 StyleBox。

### 模态 UI 规则

- 模态面板打开时锁定玩家移动和战斗输入
- 鼠标悬停 Control 上时不触发攻击
- 数字键分上下文，不全局拦截
- 弹窗打开加 0.15s 淡入 Tween
- 全屏锚定必须用 `set_anchors_and_offsets_preset(FULL_RECT)` 而非 `set_anchors_preset`

所有纹理首次运行自动生成（程序化绘制），不依赖外部素材：

- **瓦片**：33 张 PNG，星露谷式鲜亮调色板

## 八、技术信息

| 项目 | 值 |
|------|-----|
| 引擎 | Godot 4.6 |
| 分辨率 | 1920×1080 |
| 拉伸模式 | canvas_items |
| 瓦片尺寸 | 32×32 像素 |
| 角色帧尺寸 | 32×48 像素（1.5x 缩放） |
| 地图 Chunk | 16×16 瓦片 |
| 世界半径 | 120 瓦片 |
| 自动加载 | GameManager, DialogManager |
| 主场景 | res://scenes/main.tscn |
| 脚本数量 | 35 个 GDScript |
| 纹理总数 | 33 瓦片 + 72 玩家 + 800 NPC = 905 张 PNG |

### 运行时贴图架构（重要）

- 所有纹理 PNG 由 `texture_generator.gd` 程序化生成，无 import 数据
- 加载须用 `TextureGen.load_png_texture()`（`Image.load_from_file` 绝对路径解码 + 内存缓存），禁止直接 `load("res://...")`
- 检查 PNG 存在性用 `FileAccess.file_exists`，不用 `ResourceLoader.exists`
- TileSet 每次启动内存构建（`TilesetGen.build_tileset()`），不加载 .tres
- 玩家 SpriteFrames 由 `player.rebuild_sprite_frames()` 延迟一帧从 PNG 重建
- NPC 帧由 `npc_character._setup_sprite_frames()` 启动时构建

## 九、游戏技巧

1. **战斗**：善用架势切换，攻击架势输出高但易被破防，防御架势适合等反击时机
2. **修炼**：找对环境修炼事半功倍，避开五行相克环境
3. **经济**：声望越高买东西越便宜，多做任务提声望
4. **建造**：优先建农田解决饥饿，再建练功房加速修炼
5. **门派**：加入门派可习得独门武学，叛离会损失声望
6. **生存**：随时关注饥饿值，饥饿加速体力消耗形成恶性循环
7. **奇遇**：触发后右上角按钮闪烁，自行点击处理，不锁移动
8. **传承**：死亡不可避免时，传承模式可保留部分进度重新开始

| 脚本 | 功能 | 触发条件 |
|------|------|---------|
| `texture_generator.gd` | 生成所有像素风纹理（瓦片/玩家/NPC） | 首次运行或 PNG 缺失 |
| `tileset_generator.gd` | 内存构建 TileSet（含碰撞） | 每次启动 |
| `frames_generator.gd` | 生成玩家 SpriteFrames（仅供编辑器预览） | 手动 |
| `skill_generator.gd` | 生成 18 种武学技能 | 技能资源缺失 |
| `inner_generator.gd` | 生成 6 种内功心法 | 内功资源缺失 |
| `combo_generator.gd` | 生成连招树 | 连招树缺失 |
| `clan_generator.gd` | 生成 8 大门派 | 门派资源缺失 |

如需重新生成贴图，删除 `sprites/` 下对应 PNG 后重新运行即可。
