# 江湖志（KufuWorld）

> 一款基于 Godot 4.6 的 2D 武侠 RPG，气候驱动的程序化开放世界，像素风（参考星露谷物语/江湖风云传）。

你扮演一位初入江湖的侠客，在随机生成的广袤世界中探索、修炼、战斗、结交豪杰、加入门派、触发奇遇，书写属于自己的江湖传奇。世界由气候场驱动程序化生成：雪原、山地、温带、竹林、森林、平原、沙漠七种群系自然过渡，唐制城池「青石城」与七大村镇、五大门派领地依气候择址，河流自高山奔流入海。

## 一、快速开始

### 环境要求

- Godot 4.6+
- 推荐分辨率：1920×1080（拉伸模式 canvas_items）

### 运行方式

1. 用 Godot 编辑器打开项目目录
2. 首次运行自动生成全部瓦片纹理、瓦片集（约需数秒；角色/NPC 素材已随仓库提供）
3. 点击运行或按 F5 启动游戏

## 三、核心系统

### 3.1 生存系统

- **饥饿值**：持续下降，低于 20 时体力加速消耗。通过食物恢复。
- **体力值**：冲刺消耗，饥饿或受伤时恢复减慢。
- **气血**：归零触发死亡机制。通过药品恢复。
- **中毒值**：高于 50 时持续损失气血。解毒散可快速清除。
- **内力**：攻击、格挡、闪避消耗。打坐修炼可恢复。

### 3.2 战斗系统

#### 攻击与连招
- **轻攻击**（左键）：出手快；**重攻击**（右键）：伤害高
- **连招**：0.5 秒连击窗口内连续攻击触发连招加成，伤害递增
- **打击反馈**：扇形刀光特效 + 命中粒子飞散 + 伤害飘字 + 相机震动

#### 架势与破绽
- 三种架势各有优劣，合理切换是关键
- 破绽值达 80 进入**大硬直**（1.2 秒无法行动），会自然衰减

#### 格挡反击
- 格挡中被攻击开启 0.4 秒反击窗口，Q + 轻攻击触发**格挡反击**：伤害 x2，自身破绽 -30

### 3.3 内功修炼

6 种内功心法，各有五行属性：

| 内功 | 五行 | 推荐修炼地 | 内力加成 |
|------|------|-----------|---------|
| 土灵归元诀 | 土 | 洞窟 | 18 |
| 寒冰真气 | 水 | 寒潭 | 15 |
| 烈阳心经 | 火 | 火山 | 12 |
| 玄阴鬼录 | 水 | 墓地 | 5 |
| 金刚不坏体 | 金 | 山巅 | 25 |
| 青木长生功 | 木 | 竹林 | 20 |

- 匹配环境修炼速度 x2；**五行相克**环境修炼效率 -70% 且内力受损

### 3.4 武学技能

6 类武器 × 3 阶段（起手/连击/终结）= 18 种技能：拳掌、剑法、刀法、棍法、暗器、内功（如 点苍→流云剑→万剑归宗、飞蝗石→金钱镖→暴雨梨花）。

### 3.5 门派系统

#### 八大门派资源 + 五大世界领地

门派资源共 8 家（各含武学/外交/经济参数）；其中 5 派在世界上拥有实体领地，依气候择址（界碑环围合 + 主殿 + 门派专属装点）：

| 领地 | 选址风格 |
|------|---------|
| 青峰剑宗 | 温带山地南麓，剑架演武场 |
| 铁砂帮 | 荒漠绿洲 |
| 古刹禅宗 | 竹林边缘金顶古刹 |
| 药王谷 | 湖畔竹林，附药圃农田 |
| 幽冥教 | 雪原黑岩，后山禁地崖带（故意不可行区） |

- 进入门派领地后右上角出现「⛩ 门派」按钮：拜入门下、请安（贡献+5）、切磋赐教、背叛师门
- 贡献晋升：弟子 → 内门弟子 → 执事 → 长老 → 副掌门 → 掌门（0/100/300/800/2000/5000）
- 门派外交：正派结盟、正邪为敌，吞并/解散由经济/外交/战争 tick 实时模拟

### 3.6 商店系统

- 13 种商品；**供求定价**（供多降价/需多涨价）+ **声望折扣**（最高 30%）
- 卖出价为买入价 50%，定期补货

### 3.7 建造与制作

**建筑**（B 建造模式）：

| 建筑 | 花费 | 尺寸 | 功能 |
|------|------|------|------|
| 茅屋 | 15木 5石 | 3x2 | 住所，可邀请NPC入住 |
| 练功房 | 20木 15石 | 2x2 | 修炼加速 |
| 炼丹房 | 15木 20石 | 2x2 | 炼丹 |
| 农田 | 5木 2石 | 2x2 | 提供食物 |
| 围墙 | 3木 8石 | 1x1 | 防御 |

**制作站台**（数字键 6-9 摆放，靠近按 F 合成）：工作台 / 熔炉 / 炼丹台 / 篝火。

### 3.8 农耕系统

数字键 1-4 切换工具：**锄头**开垦农田 → **菜种**播种 → **水壶**浇水（农田在干燥/湿润两态间切换）→ 成熟后**采集**，另有野生浆果丛可采摘。收获物可食用或出售。

### 3.9 奇遇与誓约

- **奇遇**：随机触发 20 种事件（悬崖秘洞、高人传功、比武招亲、黑市交易……），每个 2-3 个选项影响金钱/内力/道德/声望，结算面板展示得失明细
- **誓约**：立下誓言追求目标（天下第一/富甲一方/灭魔教……），带进度追踪与里程碑

### 3.10 死亡与传承

气血归零按正邪与声望结算：**被救**（正派高声望，损 20% 铜钱）/ **囚禁**（邪派低声望，损 40% 铜钱声望）/ **传承**（传人继承 50% 武学 + 30% 铜钱）。

### 3.11 任务与主线

- **告示板可接取制**：动态任务（除恶/护送/寻宝）在任务日志「可接取」页签接取，追踪器实时显示进度
- **主线剧情**：多章节主线（当前已启动第一章），接取前不推进、接取时补记前期进度

### 3.12 NPC 系统

- **67 位 NPC**（城内岗位 NPC + 村镇 + 门派领地），**11 种外观**（武者/书生/商人/长者/神秘人/守卫 × 女性掌柜/农妇/药娘/织女等）
- **驻留日程制**：每个 NPC 有固定作息腿（岗位→家门→广场→城门），按时刻表移动与驻留
- 交互：交谈、送礼、切磋、观察、邀请入住；好感度影响交互内容
- 名牌悬停常驻、点击闪现；**出生点可达性保障**：NPC 自动生成在玩家可达瓦片上

### 3.13 青石城

唐制坊市分离城池：**坊墙围合四大居住坊 + 双市集 + 衙门/酒馆/药铺/杂货铺/市摊/水井**，四门石板官道通向四方（过河处石拱桥）。城内 NPC 各有岗位作息；城墙四门 3 格豁口铺路，与山地山口垭口网络衔接，出城即野。

### 3.14 敌人营地

野外分布山贼营地、白骨祭坛等敌人据点（锚定可达区选址，绝不落在聚落内），击杀可获掉落与任务进度。

### 地图参数

| 参数 | 值 |
|------|-----|
| 世界半径 | 200 瓦片（400×400） |
| 瓦片尺寸 | 16×16 像素 |

### 气候群系

温度场（纬度+海拔+噪声）× 湿度场（噪声+临水加湿）驱动**七种群系**自然过渡：雪原 / 山地 / 竹林 / 森林 / 平原 / 沙漠 / 湖泊。河畔 12 格自动加湿成"河谷沃野"，沙漠中穿河即绿洲带。

### 主要瓦片

| 瓦片 | ID | 可通行 | 瓦片 | ID | 可通行 |
|------|----|--------|------|----|--------|
| 草地/深色草 | 0/18 | 是 | 湿润农田 | 33 | 是 |
| 小路/石板广场 | 1/35 | 是 | 雪地/雪田/雪径 | 34/41/42 | 是 |
| 山脉/雪山 | 3/7 | 否 | 城墙/坊墙 | 40/43 | 否 |
| 水域/桥 | 5/17 | 否/是 | 界碑 | 44 | 是 |
| 沙地 | 6 | 是 | 大建筑footprint | 39 | （由建筑承担） |
| 农田 | 16 | 是 | 树木/竹/花/石/栅栏 | 4/8/9/13/14/15 | 见内 |

多格中式建筑（2~5 格贯通屋顶、重檐朱柱）由城镇布局自动选取；碎屑装饰（草丛/野花/枯枝等 55-63）按群系稀疏点缀。

### 世界生成特性

- **安全出生点**：从地图中心螺旋扫描搬入 7×7 全可通行区（连通性 BFS ≥200 格）
- **可达性三重保障**：出生点洪泛可达集 → 封闭区域自动开路（`_ensure_connectivity`）→ **山口垭口网格**（穿崖必开 3 宽沙口，间距约 18 格）+ **绝径归崖**（死路子树自动填崖），野外无死路迷宫
- **走廊宽度**：2×2 块洪泛感知窄喉，野外通行走廊 ≥2 格
- **水文**：河流源起高山、终入湖海，避城轨迹；每隔数格石拱桥（含桥 prop 视觉）
- **聚落**：青石城 1 座 + 村镇 7 个（农田/集市/渡口三模板）+ 门派领地 5 处，均避水避城择址
- **POI**：6 类模板（城镇/门派/洞穴/修炼场/古堡/集市），地形条件 + 可达性双重校验，绝不硬编码坐标
- **散石聚簇**：野外散石只贴山系 3 格带状出露，聚落/官道/农田零碰撞装饰

### 运行时贴图架构（重要）

- 瓦片/建筑纹理由 `texture_generator.gd` 程序化生成；角色/NPC 帧由 python 素材包管线导出
- 运行时加载 PNG 必须走 `TextureGen.load_png_texture()`（无 import 数据，禁直接 `load("res://...")`）
- TileSet 每次启动内存构建（`TilesetGen.build_tileset()`）；玩家帧由 `player.rebuild_sprite_frames()` 运行时重建

## 九、游戏技巧

1. **战斗**：善用架势切换，攻击架势输出高但易破防，防御架势等反击时机
2. **修炼**：找对环境事半功倍，避开五行相克环境
3. **经济**：声望越高买东西越便宜，多做任务提声望
4. **建造**：优先农田解决饥饿，再建练功房加速修炼
5. **门派**：加入门派习独门武学，叛离损失声望
6. **生存**：饥饿加速体力消耗形成恶性循环，随身备食物
7. **农耕**：锄地→播种→浇水→采集一条龙，湿润农田才长得快
8. **探索**：山地谷道必有山口可穿行，官道石拱桥通四方；死亡时传承可保留部分进度

## 十、开发与测试

### AI 辅助调试

项目集成 `godot_ai` MCP 插件：`editor_screenshot` / `logs_read` / `scene_get_hierarchy` / `node_get_properties`。

### 测试与质量保障

- **全量世界回归**：`tools/regress_world.py` 自动注入探针运行游戏，**118 项断言**覆盖群系/水文/城池/门派/村镇/桥梁/可行域/连通性/任务/NPC/预算，当前全绿
- **探针工具链**：80+ 自研 GDScript/Python 工具（机位截图走查、瓦片采样、性能画像、素材管线校验）
- **视觉走查**：9 机位截图纪律，画面结论必须来自截图工具实测

### 资源生成器

| 脚本 | 功能 | 触发条件 |
|------|------|---------|
| `texture_generator.gd` | 程序化绘制瓦片/建筑纹理 | 首次运行或 PNG 缺失 |
| `tileset_generator.gd` | 内存构建 TileSet（含碰撞） | 每次启动 |
| `skill/inner/combo/clan_generator.gd` | 生成武学/内功/连招/门派资源 | 资源缺失 |
| `tools/import_pack_assets.py` | 素材包像素人导出+逐帧着装管线 | 手动 |

如需重新生成瓦片贴图，删除 `sprites/tiles/` 下对应 PNG 后重新运行即可。
