# 江湖志

> 一款基于 Godot 4.6 的 2D 武侠角色扮演游戏，参考星露谷物语与饥荒的地图风格。

你将扮演一位初入江湖的侠客，在程序化生成的广袤世界中探索、修炼、战斗、结交豪杰，书写属于自己的江湖传奇。

---

## 一、快速开始

### 环境要求

- Godot 4.6+
- 分辨率：1920×1080

### 运行方式

1. 用 Godot 编辑器打开项目目录
2. 首次运行会自动生成纹理、瓦片集、精灵帧等资源（约需数秒）
3. 点击运行按钮或按 F5 启动游戏

### 项目结构

```
my-godot-project/
├── scenes/              # 场景文件
│   ├── main.tscn        # 主场景（游戏入口）
│   ├── npc.tscn         # NPC角色模板
│   ├── dialog_box.tscn  # 对话框UI
│   └── star.tscn        # 星星收集小游戏
├── scripts/             # 核心脚本（50个）
│   ├── Main.gd          # 主场景入口，初始化所有子系统
│   ├── player.gd        # 玩家控制器
│   ├── npc_character.gd # NPC角色逻辑
│   ├── world_generator.gd # 程序化世界生成
│   ├── game_manager.gd  # 全局游戏管理器（Autoload）
│   └── ...              # 战斗/门派/商店/任务/奇遇等系统
├── resources/           # 游戏数据资源
│   ├── skills/          # 18种武学技能（.tres）
│   ├── inner/           # 6种内功心法（.tres）
│   └── combo_tree.tres  # 连招树
├── sprites/             # 精灵图资源（自动生成）
│   ├── player/          # 玩家帧动画（72张PNG）
│   ├── npc/             # NPC帧动画（5种类型×160张PNG）
│   └── tiles/           # 瓦片纹理（21种PNG）
├── tilesets/            # 瓦片集资源（自动生成）
├── addons/godot_ai/     # MCP AI辅助插件
└── project.godot        # 项目配置
```

## 三、核心系统

### 3.1 生存系统

角色拥有以下生存属性，需要持续关注：

- **饥饿值**：持续下降，低于20时体力加速消耗。通过食物（肉包子等）恢复。
- **体力值**：冲刺消耗，饥饿或受伤时恢复减慢。充足饥饿和健康时自然恢复。
- **伤势（气血）**：降至0时触发死亡机制。通过药品（金创药、大还丹等）恢复。
- **中毒值**：高于50时持续损失气血。自然缓慢消退，解毒散可快速清除。
- **内力**：攻击、格挡、闪避消耗。打坐修炼可恢复。

### 3.2 战斗系统

#### 攻击与连招
- **轻攻击**（鼠标左键）：消耗少量内力，出手快
- **重攻击**（鼠标右键）：消耗较多内力，伤害高
- **连招**：在连招窗口（0.5秒）内连续攻击可触发连招加成，伤害递增

#### 架势与破绽
- 三种架势各有优劣，合理切换是战斗关键
- **破绽值**：被攻击时增加，攻击架势被命中增加更多
- 破绽值达到80时进入**大硬直**状态（1.2秒无法行动）
- 破绽值会自然衰减

#### 格挡反击
- 格挡状态下被攻击会开启**反击窗口**（0.4秒）
- 在窗口内按Q+轻攻击可触发**格挡反击**，伤害x2，减少自身破绽30点

### 3.3 内功修炼

游戏包含6种内功心法，各有五行属性：

| 内功 | 五行 | 阴阳 | 推荐修炼地 | 内力加成 |
|------|------|------|-----------|---------|
| 土灵归元诀 | 土 | 调和 | 洞窟 | 18 |
| 寒冰真气 | 水 | 阴 | 寒潭 | 15 |
| 烈阳心经 | 火 | 阳 | 火山 | 12 |
| 玄阴鬼录 | 水 | 阴 | 墓地 | 5 |
| 金刚不坏体 | 金 | 阳 | 山巅 | 25 |
| 青木长生功 | 木 | 调和 | 竹林 | 20 |

- 在匹配的环境中修炼速度x2
- **五行相克**：金克木、木克土、土克水、水克火、火克金。在相克环境中修炼效率降低70%，且内力受损
- 修炼圆满后获得内力加成

### 3.4 武学技能

6类武器×3阶段（起手/连击/终结）= 18种外功技能：

| 类别 | 起手 | 连击 | 终结 |
|------|------|------|------|
| 拳掌 | 直拳 | 崩拳 | 破山拳 |
| 剑法 | 点苍 | 流云剑 | 万剑归宗 |
| 刀法 | 横斩 | 回旋斩 | 裂地斩 |
| 棍法 | 扫堂棍 | 挑云棍 | 霸王棍 |
| 暗器 | 飞蝗石 | 金钱镖 | 暴雨梨花 |
| 内功 | 吐纳术 | 护体罡气 | 真气爆发 |

### 3.5 门派系统

#### 八大门派

| 门派 | 阵营 | 领地 | 声望要求 |
|------|------|------|---------|
| 少林寺 | 正派 | 少室山 | 2000 |
| 武当派 | 正派 | 武当山 | 1800 |
| 峨眉派 | 正派 | 峨眉山 | 1200 |
| 丐帮 | 正派 | 洛阳 | 800 |
| 日月教 | 邪派 | 黑木崖 | 1500 |
| 五毒教 | 邪派 | 苗疆 | 600 |
| 华山派 | 中立 | 华山 | 900 |
| 逍遥派 | 中立 | 灵鹫宫 | 1000 |

#### 门派晋升
通过贡献值晋升门派等级：弟子 → 内门弟子 → 执事 → 长老 → 副掌门 → 掌门

贡献阈值：0 / 100 / 300 / 800 / 2000 / 5000

#### 门派外交
- 正派门派之间自动结盟，与邪派为敌
- 门派之间可能发生吞并或解散
- 门派经济/外交/战争tick系统实时模拟

### 3.6 商店与交易系统

- 商店提供13种商品，涵盖武器、防具、药品、材料、饰品
- **供求定价**：供应充足时价格降低，需求旺盛时价格上涨
- **声望折扣**：声望越高，买入价格越低（最高30%折扣）
- 卖出价格为买入价格的50%
- 商店会定期补货

#### 物品稀有度

| 稀有度 | 颜色 | 最大库存 |
|--------|------|---------|
| 凡品 | 白色 | 20 |
| 良品 | 绿色 | 10 |
| 稀有 | 蓝色 | 5 |
| 史诗 | 紫色 | - |
| 传说 | 金色 | - |

| 建筑 | 花费 | 尺寸 | 功能 |

### 3.8 死亡与传承

气血归零时触发死亡，根据正邪值和声望决定结局：

| 结局 | 条件 | 效果 |
|------|------|------|
| 被救 | 正派+高声望 | 恢复部分气血，损失20%铜钱 |
| 囚禁 | 邪派+低声望 | 损失40%铜钱和声望，关押30秒 |
| 传承 | 其他情况 | 以传人身份继续，继承50%武学和30%铜钱 |

### 3.9 奇遇系统

游戏中会随机触发10种奇遇事件，包括：
- 悬崖秘洞、高人传功、市井斗殴、神秘商人
- 毒蛇袭击、河畔渔翁、荒庙夜宿、酒馆斗酒
- 古墓奇遇、侠侣相遇

每个奇遇有2-3个选项，不同选择影响金钱、内力、道德、声望等属性。

### 3.10 誓约系统

可以立下誓言追求目标：
1. 成为天下第一
2. 富甲一方
3. 灭掉魔教
4. 博学多才
5. 行侠仗义
6. 自定义目标

誓言有进度追踪和里程碑系统。

### 3.11 任务系统

- 动态生成任务：除恶、护送、寻宝等类型
- 每个任务有目标、奖励、完成度追踪
- 可同时接取多个任务
- 任务日志HUD实时显示进度

### 3.12 NPC系统

- 4位固定NPC：谢云鹤（儒雅）、铁三娘（豪爽）、柳如烟（阴沉）、老樵夫（慈悲）
- NPC有日程系统：行走、工作、休息
- 可与NPC交谈、送礼、切磋、观察、邀请入住
- 好感度系统影响NPC对话和交互
- 5种外观类型：武者、书生、商人、长者、神秘人

## 四、世界地图

地图采用程序化生成，参考星露谷物语与饥荒的风格，包含以下要素：

### 地形类型
- **草地/深色草地**：主要地形，可自由通行
- **沙地**：水域和陆地之间的过渡带
- **水域**：不可通行，世界边界和河流
- **山脉/雪山**：不可通行，高海拔区域

### 植被与装饰
- 松树、橡树、竹子、花朵（装饰层，下方有地面）

### 建筑与设施
- 城镇房屋、茅屋、寺庙、洞穴入口
- 道路、桥梁、栅栏、农田

### 世界结构
- **边界**：世界外围（半径80瓦片）为深水区域，不可通行
- **河流**：2-3条正弦曲线河流，宽度3-5格，每隔15格有桥
- **城镇**：3-5个随机城镇区域，结构为栅栏→农田→房屋+路
- **POI兴趣点**：6种类型（城镇/门派/洞穴/修炼场/遗迹/集市），各有专属地形

## 五、环境与天气

### 环境区域
- **寒潭**：水属性，适合修炼寒冰真气
- **竹林**：木属性，适合修炼青木长生功
- **山巅**：金属性，适合修炼金刚不坏体

### 天气系统
- 5种天气：晴、阴、雨、雪、雾
- 日夜循环
- 下雨/下雪时NPC移动速度降低40%
- 天气影响部分奇遇触发条件
- 粒子效果（雨滴/雪花）

## 七、游戏技巧

1. **战斗**：善用架势切换，攻击架势输出高但容易被破防，防御架势适合等待反击时机
2. **修炼**：找对环境修炼事半功倍，避开五行相克的环境
3. **经济**：声望越高买东西越便宜，多做任务提升声望
4. **建造**：优先建农田解决饥饿问题，再建练功房加速修炼
5. **门派**：加入门派可习得独门武学，但叛离会损失声望
6. **生存**：随时关注饥饿值，饥饿会加速体力消耗形成恶性循环
7. **传承**：如果死亡不可避免，传承模式可以保留部分进度重新开始

## 九、开发工具

项目集成了 `godot_ai` MCP 插件，支持通过 AI 辅助进行场景编辑、脚本修改、调试等操作。详见 `addons/godot_ai/README.md`。

### 编辑器工具脚本

以下 `@tool` 脚本可在 Godot 编辑器中运行，用于生成游戏资源：

| 脚本 | 功能 |
|------|------|
| `texture_generator.gd` | 生成所有像素风纹理（瓦片/玩家/NPC） |
| `tileset_generator.gd` | 生成 TileSet 瓦片集资源（含碰撞） |
| `frames_generator.gd` | 生成玩家 SpriteFrames 动画资源 |
| `skill_generator.gd` | 生成18种武学技能资源 |
| `inner_generator.gd` | 生成6种内功心法资源 |
| `combo_generator.gd` | 生成连招树资源 |
| `clan_generator.gd` | 生成8大门派资源 |

### 资源自动生成

首次运行游戏时，`Main.gd` 会自动检测并生成缺失的资源：
1. 纹理PNG（瓦片/玩家/NPC精灵图）
2. SpriteFrames（玩家动画帧）
3. TileSet（瓦片集，含物理碰撞层）

如需重新生成，删除对应文件后重新运行即可。
