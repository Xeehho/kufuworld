## 裁剪三条硬规矩（进件断言会查）

1. **只从透明底 PNG 源表裁**——参考图/截图/JPG 裁出来的件带底色，是废件。
2. **切线对齐 16px 网格**：平铺件（地面/墙面）长宽都是 16 的倍数；建筑件宽度=16 倍数（对齐 foot 占格），高度自由但**同排建筑同高**（建议 92~96px）。
3. **建筑底边贴画布底边**（底边锚定），檐子上方的透明留白别裁掉（檐宽≈foot 占格宽）。

命名随意（中英均可，文件夹已给类别），同款变体加 `_a/_b/_c` 后缀。
