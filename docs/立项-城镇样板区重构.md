# 立项 —— 城镇样板区（材质包 1:1 复刻试点）与 v4 全量重构规划

> 状态：**立项待批**（本文档为立项书，批准后按阶段执行）
> 提出背景：用户对比 `docs/problem/image1-3.png`（当前运行画面）与 `docs/材质包图片/image1-2.png`（目标效果），
> 判定现有城镇在**密度、道路规划、房屋精致度、布局逻辑**上与材质包差距过大，需 1:1 复刻。
> 策略：**先划试验田，再谈全量**——在游戏世界单独划出一块大面积土地做样板区，成功后推广重构。

## 一、问题定义（现状 vs 目标）

### 1.1 现状证据（docs/problem 三截图）

| 问题 | 表现 | 根因（已定位） |
|------|------|--------------|
| 城镇密度低 | 3 栋建筑散落在 20×20 格大草坪上，相互无关联 | `_place_town_building` 四象限随机选址，无地块(plot)概念；half=8~9 的镇体只放 5~8 栋 |
| 道路无规划 | 建筑与路无朝向关系；路网是十字+门前小径，没有街巷层级 | 路网生成先于建筑，建筑不消费路网信息 |
| 房屋不够精致 | 单体建筑尚可（程序化中国风），但缺少檐下道具、院墙、门窗Variation、尺寸差异 | 无院落/围墙概念，道具密度低 |
| 布局混乱 | 农田裸板漂浮、桥在草地上（已修）、灰板泼墨（已修） | 农田带无作物围栏（P4b 已装点）；选址与地物无空间契约 |
| 巨型空地 | 镇内 60%+ 面积是纯色草坪 | 无"地块填充"逻辑：院落、花园、树、杂物不参与生成 |

### 1.2 目标效果（材质包样图拆解，1:1 复刻标准）

对 `docs/材质包图片/image1.png`（农场村落）与 `image2.png`（河畔屋舍）逐要素拆解：

| 要素 | 材质包样图特征 | 量化标准 |
|------|--------------|---------|
| 街巷网络 | 主巷 2~3 宽蜿蜒连接各地块，支巷 1~2 宽进院门；路面=碎石/土路 | 主巷覆盖率（建筑门 4 格内有巷）= 100%；巷总长/镇面积 ≈ 1:12 |
| 地块(Plot) | 每栋建筑隶属一个地块：房体+前院+侧院；地块间以围墙/栅栏/绿篱分隔 | 地块数 ≥ 建筑数；无"孤儿建筑" |
| 建筑密度 | 房屋占镇区面积 ~25-35%，屋间距 1~3 格 | 建筑footprint/镇区 ≥ 22% |
| 建筑精致度 | 木框架抹灰墙+瓦楞屋顶+烟囱+窗花+门台阶+檐下桶箱 | 每栋 ≥ 4 个细节要素 |
| 农田 | 地块内作物成行（架+垄），稻草人，栅栏围合 | 农田 100% 有围栏，作物密度 ≥ 40% |
| 植被 | 镇内散布乔木/灌木/花丛/草丛，绿篱 | 镇内装饰密度 ≥ 25% 格 |
| 道具 | 木桶、货箱、干草堆、灯柱、水井、指示牌 | 每 8×8 格 ≥ 1 组道具 |
| 色彩 | 暖色草地+多样地面纹理+无大块单色 | 单色同纹 3×3 连片 = 0 |

## 二、总体策略：样板区先行（本期范围）

### 2.1 为什么先做样板区

1. **零回归风险**：现有城镇/门派/官道之间存在脆弱的空间契约（P4b 实证：仅挪动建筑锚点即触发
   `sect_count_5`/`settlement_road_no_collide` FAIL）。样板区是**新增领地**，不与任何既有系统耦合，
   regress 102 断言无需更新。
2. **快速迭代**：样板区生成器独立成模块，改一轮看一轮（同机位截图 vs 材质包样图并排对比），
   不用每次全图生成。
3. **验收驱动**：用户对样板区验收通过后，其布局算法与Prefab库即成为 v4 全量重构的施工标准。

### 2.2 样板区选址方案

- **位置**：程序化选址——在出生点平原（半径 40 格内）扫描一块 **56×44 格**（896×704px）的
  无主矩形：不与城(75,0)+外扩、四门官道走廊、7 镇 5 门派 2 湖 5 河、既有 POI 重叠；
  候选不足时放宽到半径 60。选址后登记 clearance（复用 `_register_town_clearance` 机制），
  保证 POI/NPC 生成自动避让。
- **入口**：一条 2 宽碎石路从最近官道/镇路接入样板区主巷（纯 path 铺装，无 17）。
- **立牌**：区口立"· 样板村 ·"标牌（同青石城城名标样式）。
- **开关**：`FLAG demo_town`（world_features 登记制），默认开；出问题可一键关（回归不受影响，
  因为样板区本来就不在断言覆盖内）。

### 2.3 铁律（本期红线）

1. 样板区内**一切内容为纯视觉**：建筑用 decor-prop 形态（Sprite+可选StaticBody），
   不写 override 占格、不进 collision_tiles、不登记 NPC 岗位、不产生任务/商店交互。
2. 不修改 `_generate_towns`/`_generate_city`/`_generate_sect_territories` 的任何选址行为。
3. 每阶段结束必须跑 `regress_world.py`（102 全绿）+ 样板区同机位截图入库 `docs/shots/demo_*`。

## 三、目标视觉规格（样板区布局总图）

样板区 56×44 格，参照材质包 image1 的村落结构：

```
┌────────────────────────────────────────────────┐
│  果树带(疏林+草丛)                              │
│   ┌────────┐    ┌────┐   ┌──────────┐          │
│   │谷仓地块 │    │水井 │   │温室地块*  │          │
│   │6x5大屋 │←主巷→│广场│───│5x4玻璃顶 │          │
│   └────────┘    └────┘   └──────────┘          │
│  ═══════════ 主巷(2宽碎石) ═══════════          │
│   ┌────┐  ┌──────┐    ┌─────┐   ┌─────┐       │
│   │农舍 │  │长屋   │    │农舍2│   │杂货铺│        │
│   │4x3 │  │6x4   │    │4x3 │   │4x3  │        │
│   └─┬──┘  └──┬───┘    └──┬──┘   └──┬──┘       │
│   ═支巷════╝           ═══支巷═══════╝          │
│   ┌──────────────┐  ┌──────────────┐           │
│   │菜圃A(6x4围栏) │  │菜圃B(5x4围栏) │           │
│   │作物行+稻草人   │  │作物行+棚架    │           │
│   └──────────────┘  └──────────────┘           │
│  河畔带（接现状水域或自挖装饰池塘8x6+码头）        │
└────────────────────────────────────────────────┘
* 温室=材质包 image1 标志物：玻璃顶+木框，程序化绘制
```

- 建筑共 6~8 栋（谷仓/长屋/农舍×3/杂货铺/温室），密度 ≥22%
- 三级路网：主巷 2 宽（碎石 path）→ 支巷 1 宽（土路）→ 门前台阶
- 每地块围栏围合（Farm.png 栅栏），地块内前院铺装+道具组
- 全区装饰密度 ≥25%（草丛/野花/灌木/树），道具每 8×8 ≥1 组

## 四、技术方案

### 4.1 新模块：`scripts/town_demo_kit.gd`（挂 World 下，FLAG 门控）

```
town_demo_kit.gd
├─ find_site()            # 选址扫描（避让一切既有领地，登记 clearance）
├─ build()                # 总入口：骨架→地块→建筑→装点
│  ├─ _lay_roads()        #   三级路网（主巷/支巷/门前台阶）
│  ├─ _stamp_plots()      #   地块划分（记录 rect 供建筑/院落消费）
│  ├─ _place_house(kind, plot)  # Prefab 建筑合成+落位（面朝巷道）
│  ├─ _build_yard(plot)   #   院落：围栏+前院铺装+道具组
│  ├─ _build_farm(plot)   #   菜圃：围栏+作物行+稻草人/棚架
│  └─ _scatter_decor()    #   全区植被+道具散布
└─Prefab 库（compose 函数，全部程序化+素材包组件）
   ├─ _compose_gable_house(w,h,roof_style)   # 木框抹灰墙+三角瓦顶（Walls/Roofs 组件）
   ├─ _compose_barn(w,h)                     # 谷仓：大体积+大门+干草窗
   ├─ _compose_greenhouse(w,h)               # 温室：玻璃顶（半透明青）+木框
   └─ _compose_shop_stall(w,h)               # 杂货铺：出檐+货台
```

### 4.2 建筑精致度规格（Prefab 内部要素，每栋 ≥4 项）

1. 木框抹灰墙：Walls.png 抹灰底+深木框线条（程序化描框）
2. 屋顶：Roofs.png 瓦楞纹样调制（复用 `_roof_pat` 管线）+ 烟囱（含烟囱口暗部）
3. 门窗：门+台阶+双侧窗（窗框/窗台），大屋加阁楼窗
4. 檐下：桶/箱/干草堆道具 1~2 组
5. 阴影：脚底宽椭圆（复用 `make_shadow_sprite`）

### 4.3 与现有系统的关系

| 系统 | 关系 |
|------|------|
| world_generator | 只调用 `town_demo_kit.build()`（_ready 尾部、_dress_farm_bands 后），其余零改动 |
| TileSet | 沿用现有 67+ 瓦片（path/石板/农田/花/栅栏），新增瓦片从 ID 67 起 |
| farm/station/NPC | 不交互（样板区无 NPC、无可交互物） |
| regress | 零断言新增/修改；样板区选址走 clearance 通道，天然避让 |
| 性能 | 预算：props ≤ 400 节点、Sprite ≤ 250 张纹理；选址扫描 O(半径²) 一次性 |

### 4.4 已知风险与对策

| 风险 | 对策 |
|------|------|
| 选址失败（平原被占） | 候选半径放宽 40→60→80；最终兜底=关闭 FLAG 并告警，不阻塞游戏 |
| 样板区被野怪营地/NPC 刷新污染 |营地选址查 clearance（已有机制）✓；野怪不查——加白名单过滤（W6 zone 表排除 rect） |
| prefab 视觉不像材质包 | 每阶段截图 vs 样图并排走查，逐项打勾（下方验收清单），禁止印象式通过 |
| Y-sort 遮挡错乱 | 全部 prop 沿用"原点=脚底"约定（P4 已验证） |
| 将来 v4 推广时的空间契约 | 本期不动契约；v4 立项时一并重排（见第六节） |

## 六、v4 全量重构立项（样板区验收通过后启动，本文档只立框架）

1. **范围**：`_generate_towns` 换用 town_demo_kit 的地块式布局（7 镇全部重排）；青石城坊内
   密度增强（里坊巷道+院墙）；门派山环内的殿堂区庭院化
2. **断言**：regress 登记制升级 v4——镇建筑锚点改为"记录制+关系断言"（门在巷边/地块围合），
   废除对具体坐标的隐式依赖；`sect_count_5`/`settlement_road_no_collide` 等空间契约断言
   按新布局重排
3. **风险**：全图空间重排影响 NPC 锚点/任务地点/奇遇点位——需要一次全量走查
4. **里程碑**：M1 单镇改造（farm 模板）→ M2 全 7 镇 → M3 青石城坊内 → M4 门派殿堂区
