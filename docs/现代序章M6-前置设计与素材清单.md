# 现代序章 M6——前置设计与素材清单（美术重构 Slice F 前置，2026-09-06）

> 定位：M6（便利店现代序章，设计稿 §九 S1~S7，约 10 分钟流程）开工前的准备件。
> 本文全部内容**不依赖 Cozy Town 购入**——包到位前可先做 §5 程序化灰盒，包到位后按 §4 清单换皮（长安 M0 灰盒→精雕同款策略）。

## 一、目标与边界

- **M6 本体**：便利店室内 + 夜街两个现代迷你场景 + S1~S7 序章剧情流程 + 穿越演出。
- **本文前置件**：场景接入方案、瓦片 ID 规划、素材需求清单（对口 Cozy Town / 免费兜底 Pixel Spaces）、程序化灰盒先行方案、验收标准。
- **不在范围**：剧情文案细写、糖糖系统三件套（面板/仓界/商城——设计稿 §七 另行立项）。

## 二、场景接入口设计（复用既有模式，零新架构）

1. **偏移空间模式**：现代场景挂 `World` 下 y=80000 偏移空间（长安用 y=40000，互不干扰）——玩家节点不重挂（survival_hud/小地图等按 `/root/Main/World/Player` 路径引用的既有约束），冻结/解冻复用 city_visit 七系统清单。
2. **流程链路**（与现有系统衔接点）：
   - 新档开场 → 玩家落在**便利店**偏移空间（现代装 `player_modern`，`player_appearance="modern"` 已是默认值 ✓）
   - S1~S3 便利店/夜街剧情（对话+交互+首个道德选择，全部复用 DialogManager/apply_story_effects）
   - S4 濒死演出（黑白画面=CanvasModulate 灰化 + 糖糖首语，程序化演出）
   - S5 **穿越时刻** = 场景切换到开放世界陈家村（复用 city_visit 出城式回落），玩家保持 modern 装
   - S6~S7 → 交接给现有主线：主1「醒来」（石伯）→ 主1 完成自动换唐装（`player_skin:tang` 已挂 ✓）
   - **双外观链路天然闭环，无需新代码**——M6 开工前已就位（3be9342）
3. **主线节点挂接（需拍板）**：现 `main_story.gd` 主1~5 是旧武侠序章试验段。设计稿新序章 S1~S7 与其**部分重叠**（S5≈主1 醒来、S7 伏笔）。两个方案：
   - **A（推荐）**：新增 `prologue_modern.gd` 独立驱动 S1~S4，S5 起把 `story_stage` 交给现有 main_story（旧主1~5 保留为穿越后剧情，主1 文案微调衔接"濒死醒来"）；
   - B：重写 main_story 全节点。工作量大一档，M6 不做。
4. **门面/触发**：便利店门=夜街入口（内景门垫模式，同魏王府）；夜街东端路口=S3 车祸演出触发区（Area2D）。
