## 关键事实速查（已核实，避免重复调查）

- **⚠️ build 顺序契约（P0 踩坑）**：override 写入（平整/铺路）**必须先于 `_load_zone_chunks`**——
  override 上漆只发生在 `_load_chunk` 一次性执行，后写不上屏（首版入口路因此隐形，已修）
- **选址否决分布实测（半径150/1963候选）**：hard(山611/水253/雪山147/39建筑123) 1168、city 399、
  border 373、clear 15、road_band 6——"零山零水 56×44 净地"全图不存在，故 GEO_TILES(3/5/7)
  允许 ≤15% 并在 `_flatten_ground` 平整为群系地面（呼应立项书 §三"接现状水域/自挖池塘"）；
  人工领地瓦片 BUILD_TILES 零容忍
- **TownDemoKit 常量/方法**（`scripts/town_demo_kit.gd`）：
  - `wg` = WorldGenerator 引用（无类型）；`rect: Rect2i` 选定区；`gate_in: Vector2i` 区口内侧
  - `setup(world_gen) -> bool`：网格扫描选址（必须先于 build）；`build()`：登记+骨架
  - `_site_reason` 返回否决原因码（""=过）：A 界/城剪枝 → B rect 内步长2 扫描（BUILD 一票否决 +
    GEO ≤15% + 植被 ≤26%）→ C 外扩2框带官道set/净空全扫；`_gate_reachable`：官道最近格距 rect ≤55
  - `_stamp_prop(png, cell)`：脚底锚定 z=2 无碰撞 prop（挂 demo_kit 自身，World 递归 Y-sort 吸收）
  - `_pave(c)`：`wg.override_cells[c] = wg._palette_at(x,y)["path"]`（plains=瓦片1）
- **回归/探针契约**：

    ——样板区纳入该判定后营地会被外推出区，断言仍绿（2026-09-02 实测 PASS）
