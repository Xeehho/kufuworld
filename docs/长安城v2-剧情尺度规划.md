## 二、设计原则：剧情定尺度

### 2.1 为什么 30 街区够

剧情 MD 里长安承担的功能逐一盘点后，可归并为 **12 类功能分区**（每类 1~2 格）：

| 功能区 | 剧情出处 | 归并逻辑 |
|---|---|---|
| 宫城·太极宫（太极殿/两仪殿） | 2-6 认主、朝堂事件、终幕摊牌 | 2 格合并 |
| 太子东宫 | 终幕党争风暴眼 | 1 格 |
| 皇城官署带（京兆府/大理寺/御史台/鸿胪寺/将作监/太医署/秘书省 + 鸿胪寺侧胡邸） | 下狱/外交/营建/药王线/印刷术 | 2 格合并，8 署门面沿街 |
| 国子监（与房府同坊，史实） | 2-3 国子监之辩 | 并入务本坊 |
| 西市（琥珀光酒肆/主角工坊/柜坊质库当铺/波斯粟特邸/绸缎药书铺） | 2-1 立足、2-2 微服夜访、经营主阵地 | **2 格合并**（剧情最重的商业区） |
| 东市 | 高端消费 | 1 格 |
| 平康坊·天香阁 | 3.5.3 青楼全玩法 | 1 格 |
| 名臣功臣府（长孙/房/魏征/程/李 + 尉迟/秦/侯/高/阎） | 死党大本营/军门/恩师群 | 3 格（崇仁/务本/永兴+宣阳群像） |
| 王府公主府（魏王/吴王/晋王/长乐公主/怀化郡王） | 夺嫡线/种痘病家/北疆情报 | 3 格（延康/胜业/宣阳+长寿） |
| 士族府群（清河崔/博陵崔/范阳卢/兰陵萧/诸望） | 主反派崔氏 + 士族线 | 1 格（崇义坊，群像并置） |
| 寺观（大兴善寺/玄都观/弘福寺/大慈恩寺雁塔） | 佛道事件/玄奘线 | 4 格 |
| 曲江池·芙蓉园 | 节庆演出 | 与大慈恩寺合并 2 格（晋昌坊） |
| 日常居民 | 城市生活感、NPC 栖所、（可选）主角自置宅 | 4~6 格纯居民坊 + 各坊散宅 |

加上北衙军营（终幕党争军权锚点）、万年县衙（1-6 献犁）、客栈邸店（入京落脚）、击鞠场（马球）、大明宫预留地（四幕扩建），合计 **30 格正好铺满 6×5 网格，一格都不浪费**——这就是"剧情定尺度"：不预留任何"史实有但剧情不用"的空坊。

### 2.2 2D 尺度预算

| 指标 | v2 | 依据 |
|---|---|---|
| 横穿时间 | 152 格 ÷ 约 5.5 格/秒 ≈ 28s | v1 实测 65~80s 被用户判"太大" |
| 一屏内容 | 40×22.5 格 | 1920×1080 / zoom3 / 16px 瓦 |
| 街区 vs 一屏 | 20×20 街区 ≈ 半屏宽 | 一眼读懂一个坊，两屏走完一个区 |
| 主干路口间距 | 24 格（街区20+街4） | 4~5 秒一个路口，逛城节奏感 |

## 三、道路规划（分级 · 走向 · 剧情理由）

### 3.1 道路分级表

| 等级 | 名称 | 宽 | 走向 | 剧情理由（道路合理性依据） |
|---|---|---|---|---|
| L0 | **朱雀大街** | 6 | 中轴纵缝（第2～3列间），明德门→皇城南门**朱雀门**（再经皇城中轴抵达宫城承天门） | 元日朝会、渭水受降凯旋、上元灯会三大演出主舞台；玩家城市认知主轴 |
| L1 | **金光门·春明门大街** | 4 | 第1～2排间横缝（皇城南缘第一横街），开远门↔春明门贯通 | 商队入京动线（1-8 从灞桥进春明门）；串西市北缘/皇城前/东市；玄奘出城走开远门（史实名：金光门—春明门大街） |
| L2 | **城南横街** | 4 | 第3～4排间横缝 | 城南生活动线；上巳节曲江人流行进路线 |
| L3 | 纵街 ×4 | 4 | 第0～1、1～2、3～4、4～5 列间纵缝 | 第4～5 纵街（东纵街）=玄武门→金光春明大街的**凯旋行军线**；西纵街伴清明渠 |
| L4 | **环城街** | 3 | 沿城墙内圈一周 | 宵禁夜行合法通道（"大街可走、两市闭门"的环路兜底） |
| L5 | 坊内巷 | 2 | 各街区内部 | 居民坊排屋肌理（v5 样式：巷 2 宽） |
| — | 市内十字街 | 3 | 西市/东市内部 | 两市内部通道，市墙 4 门（宵禁册仅两市） |

> 第2～3排间横缝（西市南缘一线）为普通 4 宽横街，其中西市段被市墙吸收（西市两格合并）。宫城与皇城之间的承天门横街为宫苑内街（一级只做宫区轮廓，入内属二级）。

### 3.2 四条剧情动线（验收路网用）

1. **入京动线**（1-8）：灞桥(开放世界)→春明门→金光春明大街西行→朱雀大街十字→西市北门 / 安邑坊客栈。沿途第一印象：城门楼→街景→市楼。
2. **凯旋动线**（3-6 渭水受降）：渭水桥(开放世界)→玄武门→东纵街南下→金光春明大街→**朱雀大街北上**→朱雀门(皇城南门)→皇城中轴→承天门献俘。沿街可站仪仗与人群。
3. **夜行动线**（宵禁玩法）：暮鼓后市门闭、坊无墙——环城街+五纵二横大街任意游走，目标平康坊天香阁（风月场所宵禁不闭，史实平康特性）。
4. **节庆动线**（上元/上巳）：明德门→朱雀大街（灯会）；城南横街→晋昌坊曲江（曲江宴/祓禊）。

> 动线即回归断言：v2 灰盒落地后，E2E 探针按这 4 条路走一遍取样。
