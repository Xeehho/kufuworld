# 江湖志 前期验收标准（回归走查基准）

> 适用范围：游戏前期（出生→探索→生存→战斗→建造→经营→任务→奇遇完整闭环）
> 走查方式：真实运行态操作 + 截图视觉审计 + 逻辑探针
> 严重度分级：P0阻断（流程跑不通/数据错位）｜P1高（明显穿模/交互失效/展示错误）｜P2中（边距字号微调）｜P3低（可优化）

---

## 一、功能逻辑验收（全部必须可跑通）

### 1. 移动与视角
- [ ] WASD/方向键四向移动流畅，无卡墙、无穿地形（水/山/雪山/房屋不可通行）
- [ ] 沿墙滑动正常（贴墙移动不被锁死）
- [ ] 相机跟随玩家，无出界露出黑边
- [ ] 安全出生点生效：开局不出生在水/山/建筑内

### 2. 战斗系统
- [ ] 左键轻击/右键重击有攻击动画+命中判定（近战扇形）
- [ ] Q格挡消耗内力并有格挡指示；空格闪避位移+绿色指示
- [ ] Z/X/C 三架势切换，CombatHUD 架势条同步
- [ ] 敌人（营地山贼/白骨教众）仇恨圈追击→蓄力预警（变黄）→命中玩家有红闪+击退+相机震动
- [ ] 击杀敌人播死亡帧+掉落入背包；90s后且玩家远离才重生
- [ ] 玩家死亡→死亡画面→复活复位，属性正常

### 3. 生存与工具（星露谷式）
- [ ] 数字键1-4切换锄头/水壶/菜种/采集，再按收回徒手；切换有飘字反馈
- [ ] 锄头开荒：草地→农田；水壶浇水：农田→湿润农田（颜色可见变化）
- [ ] 种菜→浇水→3天成长→成熟→采集入库全链路；雨天自动补水
- [ ] 浆果丛采集得野浆果，空丛2天再生
- [ ] E打坐：进入/退出打坐状态，内力恢复；再按E或移动可退出

### 4. 建造系统（饥荒式）
- [ ] B进入建造：面板停靠右侧（不挡屏幕中心），B/ESC均可退出
- [ ] 建造状态下人物可自由移动（WASD+Shift疾跑）
- [ ] 数字键1-9选建筑，选中项高亮金色
- [ ] 幽灵预览跟随鼠标吸附网格，仅在玩家手边（约两格56px）范围内放置
- [ ] 绿格=可建/红格=不可建（水域山地），颜色与实际可建性一致
- [ ] 左键放置扣材料（木/石），材料不足有提示；站台类（6-9）可F键合成
- [ ] 建造菜单文字不穿模、不溢出面板

### 5. 背包系统
- [ ] I键开关背包，ESC也可关闭；容量显示 n/45
- [ ] 45格上限：装满后继续获得物品被拒（不掉数据）
- [ ] 格子显示：物品类型色块+数量角标（>1时）
- [ ] 悬停显示物品详情（类型/名称/描述/效果）
- [ ] 点击消耗品/秘籍→使用生效（血量/内力/饱食变化）；点击装备→装备生效
- [ ] 掉落/合成/购买/采集的物品正确入包；开背包时移动被锁定（模态）

### 6. 商店系统
- [ ] K开关商店；Tab买卖切换；数字键选商品；R穿戴
- [ ] 买卖扣/加金钱正确，背包同步；ESC关闭

### 7. 任务系统
- [ ] N开任务日志抽屉（左缘滑出）；展开时数字键1-9接任务（且不触发切工具）
- [ ] F1放弃首个任务；★钉选任务出现在左侧追踪器
- [ ] 追踪器进度条实时刷新（0.25s轮询）；完成任务有奖励+事件流反馈
- [ ] 角标=进行中数量，接受/放弃/完成后即时同步

### 8. 奇遇系统（最高优先级）
- [ ] 奇遇触发（约30s冷却+概率）自动弹出面板并置顶，无需手动点按钮
- [ ] 弹出时强制打断：建造/商店/任务日志/人物档案/NPC交互/对话框全部关闭
- [ ] 数字键1-9或点击选项结算，得失明细展示（金钱/内力/道德/声望/伤害/中毒）
- [ ] 铜钱不足的选项被拒绝并提示；结果视图点击继续/任意数字键关闭
- [ ] ESC/[0]/离开按钮可关闭面板

### 9. NPC交互
- [ ] 左键点击NPC=信息面板（不误触攻击）；悬停高亮+名牌显示
- [ ] F近距离交谈→交互菜单（交谈/送礼/切磋/观察/邀请/离开）
- [ ] ESC关闭交互菜单；进入门派地盘显示门派按钮

### 10. 门派/立誓/事件流
- [ ] J加入门派（声望门槛）、P查看门派、T背叛
- [ ] 立誓面板五选一，新誓替旧誓
- [ ] 右上EventHUD事件流8秒自动淡出

### 11. 昼夜/天气/世界
- [ ] 时间流逝：时辰牌更新，昼夜光照平滑过渡
- [ ] 天气（晴/云/雨/雪/雾）切换有视觉差异；雨天农田自动湿润
- [ ] 树影随昼夜强度变化；群系（森林/竹林/沙漠/雪原/湖泊/山脊）风格分明
- [ ] 城镇/POI可达：无围死区域，入口可进入

### 12. 存续底线
- [ ] 连续运行10分钟无内存报错、无脚本ERROR刷屏
- [ ] 全部面板反复开关10次无状态残留（残影/错位/重复实例）

## 二、页面交互验收

- [ ] **模态互斥**：任意时刻最多一个模态面板；打开A时打开B，A被正确打断或B被拒绝，绝不同时激活两个输入上下文
- [ ] **输入上下文正确**：数字键按上下文分派（商店内选商品/奇遇面板选项/任务日志接取/建造选型/平时切工具），无跨上下文串台
- [ ] **鼠标语义**：悬停任何UI控件时不触发世界内攻击/工具；点击NPC不攻击；点空地才攻击
- [ ] **ESC层级**：ESC按「最上层模态先关」逐层退出，一次只关一层
- [ ] **锁定规则**：对话/商店/奇遇/立誓/人物档案/背包/NPC交互/任务日志展开任一开启时，玩家移动与战斗锁定
- [ ] **焦点安全**：按钮不捕获键盘焦点（空格不会误触按钮）
- [ ] **开启动画**：弹窗统一0.15s淡入；任务日志抽屉滑入滑出；无生硬瞬现

## 三、页面展示验收（前端视觉标准）

### 1. 布局与边距
- [ ] 所有面板/弹窗与屏幕边缘保持≥16px间距，不紧贴屏幕边缘
- [ ] 面板内部元素与面板边框保持≥10px内边距，不紧贴边框
- [ ] HUD之间无重叠遮挡（左上属性盘/左侧任务追踪/右上门派按钮/右上奇遇按钮/事件流/时辰牌各居其位）
- [ ] 列表行间距均匀，文字不与分隔线/其他元素叠压

### 2. 文本与可读性
- [ ] 文字不穿模：不溢出面板边界、不与色块/图标重叠、不被截断（标签自动省略或换行）
- [ ] 中文文案无乱码；字号层级清晰（标题>正文>提示）
- [ ] 文字与背景对比度足够（深色底配浅字，禁深底深字）

### 3. 视觉一致性
- [ ] 全部面板使用统一UITheme（墨色底+描金边+圆角），无突兀白底原生样式
- [ ] 按钮三态（常态/悬停/按下）可见；弹窗风格统一
- [ ] 像素风渲染：纹理nearest无模糊；角色/瓦片比例协调（角色约2格高）
- [ ] 世界层遮挡正确：人站树前/树后遮挡关系符合Y-sort；建筑/树无半截渲染
- [ ] 层级正确：飘字/特效在最上层；面板盖住世界但不盖住更上层弹窗

### 4. 状态反馈
- [ ] 任何操作都有可见反馈：成功黄字/失败红字飘字、按钮悬停变化、音效
- [ ] 血量/饥饿/中毒低值有视觉警示（脉动/变色）
- [ ] 加载/生成分支无白屏裸窗口

## 四、走查方法

1. **逻辑项**：运行时探针自动化断言（tools/probe_*.gd + run_probe_*.py）+ 人工操作
2. **视觉项**：窗口模式跑游戏，editor_screenshot/手动截图 → 视觉分析逐项审计（穿模/边距/遮挡/对比度）
3. **交互项**：模拟按键序列真实操作（开面板→输入→关闭→复开），断言状态与展示
4. **结论分级**：P0必须修→P1应修→P2记录待排期→P3备忘；末尾给「通过/需修复后复验」结论
