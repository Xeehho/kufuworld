# 长安城 v2 材质制作清单（区域对应版·Tiled 开工用）

> 用途：你在 Tiled 里逐格做材质的**总清单**——每个区域叫什么、在哪、画布多大、要画哪些件、每件建议规格。
> 格位契约：`data/changan_city_v2.json` 的 `blocks[].col/row/span` 就是下表的格位，材质做好后按格导入（换皮不换结构）。

## 一、开工前须知（Tiled 规格）

1. **基本单位**：1 瓦片 = 16×16 px；1 街区 = 20×20 瓦片 = **320×320 px 画布**；合并格（宫城/皇城）= 20+6+20 = 46 瓦片宽 = **736×320 px**。
2. **命名规范**：每件 PNG 命名 `<区域id>_<部件>.png`（区域id 见下表，如 `pingkang_主楼.png`、`xishi_琥珀光.png`）——导入管线按区域 id 映射回格位，名字里带中文没问题。
3. **Tiled 设置**（本机 Tiled 1.12.2 实测）：collection 型 tileset + 1px 网格对齐；**图层编码必须 base64**（csv 会静默失败）；先摆一段验证拼缝再量产。
4. **建筑纪律**（长安考古结论，违反即穿帮）：整屋切片禁半截；建筑 sprite **底边锚定**瓦片格线；檐宽≈foot 占格宽（防越墙压邻）；同排建筑画布同高（防脚线参差）；大件（城门楼/塔/殿）单件 prop，**禁止**用小瓦片拼大构件。
5. **碰撞不用管**：墙体/建筑占格碰撞由生成器按结构加，你只管画面。

## 五、建议交付节奏

1. **第一批（骨架）**：S1~S4 地面 + W1 城墙 + W2/W3 城门楼 → 城市轮廓成形，替换灰盒即可走查拍照
2. **第二批（主线五区 P0）**：宫城 → 皇城 → 西市 → 平康 → 崇仁 → 出「入京动线」实机样张（明德门→朱雀→皇城→西市）
3. **第三批（P1 剧情坊）**：寺观/府邸/县衙客栈/东市
4. **第四批（P2 群像）**：排屋变体铺满居民坊 + 群像府门换匾 + 大雁塔
5. **每批交付方式**：Tiled 里按格拼好 → 发 .tmx（或导出 PNG+清单）→ 说「继续长安v2材质导入」，我解析进生成器跑探针+样张
