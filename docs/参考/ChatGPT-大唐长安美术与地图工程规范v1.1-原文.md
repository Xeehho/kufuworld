# 《大唐长安》2D RPG 美术与地图工程规范

## ——基于现有商业素材包 v1.1

> **核心目标：使用现有商业素材，搭建出类似经典 2D RPG / Stardew Valley 式的可游玩唐代长安。**
>
> 本项目不是素材制作项目，而是**素材解析、Tile Map 组装、场景设计、碰撞、图层与摄像机实现项目。**

# 1. 最重要的项目原则

## 1.1 禁止 AI 自己"发挥美术"

AI 的职责：

> **组合已有素材。**

而不是：

> 创造新的唐风美术。

# 3. 修改后的核心 Tile 规范

## 3.1 原生 Tile：48×48

**本项目当前默认 Tile 单位：**

> ### 48 × 48 px

原因不是人为规定，而是你的素材本身已经体现出了这个网格体系。

例如：

```text
768 ÷ 48 = 16
```

因此你的：

```text
768 × 768
```

素材可以理解为：

```text
16 × 16 Tile
```

而：

```text
768 × 720
```

则对应：

```text
16 × 15 Tile
```

> **"玩家脚下是什么。"**

> **Gameplay Structure**

```text

├── Walkable Area
├── Collision
└── Connection
```

```text

陆地
```

玩家必须能：

> 陆地 → 桥 → 陆地

# 18. NPC 层

NPC 不应该参与地图 Tile。

独立：

```text
NPC Layer
```

NPC 的世界位置最好也使用：

```text
Tile X
Tile Y
Offset X
Offset Y
```

而不是完全锁死在 Tile 中央。

这样人物会更自然。

---

# 19. 玩家尺寸

这里不要机械规定"必须 24×32"。

应该：

> **以你现有角色素材的原生尺寸为准。**

但是必须满足：

```text
玩家高度
≈ 建筑门高度的合理比例
```

验收标准不是"多少像素"。

而是：

> **玩家站在房屋门口时，看起来像一个真实可进入的游戏空间。**

```text
      │
      🧍
```

```text

🧍
```

```text
🧍
```

**你现在已经具备做出之前那张"长安城游戏画面"的美术基础了。**

尤其是你给的 `tile-B-05` 和 `tile-B-02`：

> **桥、船、树、灯笼、盆景、摊位、围栏、石构件、水域、建筑构件……已经足够支撑一个非常丰富的唐风街区。**

所以接下来**不要继续买素材，也不要继续让 AI "生成更好的材质"。**

真正值得做的是下一步：

### **把这四张素材进一步"工程化解析"。**

我可以继续帮你做成下面这种东西：

```text
tile-B-01
├── 48×48 Tile #001 → 石墙
├── 48×48 Tile #002 → 木墙
├── ...
│
tile-B-02
├── Bridge_Stone_01
├── Bridge_Wood_01
├── Lantern_01
├── Tree_Willow_01
├── ...
│
tile-B-05
├── Boat_01
├── Market_Stall_01
├── Tree_02
├── Pot_01
└── ...
```

然后进一步定义：

**"这些素材究竟应该如何拼成一栋房子、一个街区、一条河、一个市场。"**

这一步做完之后，你的 AI 就从现在的：

> **"凭感觉搭地图"**

变成：

> **"按照素材数据库 + 地图规则搭地图"。**

这才是让最终画面真正稳定达到你最开始那张**"大唐长安 + 2D RPG"**目标的关键。
