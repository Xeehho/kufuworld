## 〇、为什么之前会犯错（根因复盘，防再犯）

| 根因 | 表现 | 对策 |
|---|---|---|
| "整窗切片"≠"内容切片" | 切片窗口按 96px 网格整窗裁，窗内常粘邻件残片（board_notice 带半只木桶、lantern_std_red 带整根第二杆、firepit 带灯头） | 每个新切片必跑连通分量+列剖面实测（§四-1），残片=重切 |
| "格子空闲"≠"语义合理" | 道具只查 `_dressing_cell_free` 就摆，旗帜立路边、杂物堆门口、灯架堵街心 | 每类道具有语义位（§一/§三），随机摆点必须先过语境判定 |
| 只查"格"不查"像素外扩" | 民居 sprite 檐宽≈6 格而 foot 2~4 格，贴墙放必越墙压邻院；酒坛 93px 宽摆院心必穿模 | 摆放前按 sprite 实际像素宽算外扩圈（§三-3 横向间距算术） |
| 素材朝向≠场地轴向 | 侧视横构图拱桥放在纵向过河点上=横躺 | 桥/门/桌类素材先验朝向（§三-4） |
| 验收只问被反馈的问题 | 修了"接水"没问"朝向对不对"，修了"堵路"没问"对称不对称" | 验收按本文清单穷举（§五），不按反馈点裁剪 |

## 一、人的行为逻辑（道具服务于人的活动）

- [ ] **进城动线**：门→引道→桥→对岸全程瓦片连续无缝（护城河桥两端必须落在 T_MAIN_ROAD/T_QUAY 上，禁止接水）。
- [ ] **停车马/轿**：只停路缘车道（主路最外 2 格）或市场边缘/宫门侧；禁中轴、禁路口（横街带 band 检查）、禁门洞 3 格内；比例 ≤ 相邻建筑檐口 1/2。
- [ ] **旗帜/幌子**：只挂店门侧（SHOP_SIGN 机制）、酒肆/茶楼檐下、市门/城门两侧（成对）；**禁止孤旗立路边**。
- [ ] **告示牌**：城门内/坊门旁/市口（人停留处），靠墙立。
- [ ] **灯**：门口/桥头成对；街灯沿街等距成列；**禁止单只堵街心**（lantern_pole_pair 类大灯架只贴墙/北墙）。
- [ ] **杂物（坛/凳/盆景）**：靠墙根堆放（四邻 1 格内有墙=墙根），避门口甬道与门轴；**禁止散摆院心/街心**。
- [ ] **扫帚类小件**：贴铺面角落靠墙（同上墙根规则）。

## 二、房屋视觉逻辑（看起来是正常的房子）

- [ ] 每栋可见建筑=门/窗/屋顶/墙齐全的整屋切片，禁半截屋（切片被窗口切断）。
- [ ] 同屏建筑透视统一（全是正立面/斜俯视，禁"掀顶剖面"混正常立面）。
- [ ] sprite 外扩（檐宽≈6 格）不得跨墙压邻院/邻楼（檐压**本院**墙=正常出檐）。
- [ ] 院落=组群围合（正房+倒座/厢房+院墙+门楼+庭院），禁散楼平铺堆叠。
- [ ] 后排建筑允许被前排遮挡，但不得被树/草/杂物盖到"只露一行瓦"（装饰避让建筑 sprite 圈）。

## 三、城镇建造逻辑（摆放/布局/道路/桥梁）

- [ ] **桥**：桥长轴必须平行于通行方向（跨东西向河=南北纵桥）；可穿行（z=1 玩家层下或 y-sort 镂空）；两端接引道；桥头石灯/狮**中轴对称**（pcx±n 等距）。
- [ ] **道路**：等级连续（御道→主干→坊街→巷），路面道具不占 2 格净宽通道。
- [ ] **院落布局**：9×9 四合院 2×2 背靠背，避坊内十字街；全部建筑 sprite 外扩 ≤1.5 格留在院内。
- [ ] **横向间距算术对账**：同带摆放列表必须先算锚点坐标查重+互距（≥4 格；大 sprite ≥96px 距桥轴/门轴 ≥12 格）——**willow 与石灯同点叠放是真实事故**。
- [ ] **对称律**：门楼/城门/桥头两侧物件中轴对称；街灯等距；违反即改。

## 四、自然逻辑（树/草/水）

- [ ] **树**：只长在草地/园池/土格（禁方砖 T_PAVE、夯土 T_LANE 中部的孤树要贴墙根）；树位避建筑 sprite 圈（96px 冠）；行道树沿路列植等距。
- [ ] **草地**：只在园池口袋（院墙内），禁蔓延出墙/怼檐口线/嵌路面。
- [ ] **水**：水面=真实水瓦（112），禁被画死水纹的 sprite 覆盖（切片禁内嵌水/地面——bridge_arch_stone 教训）。
- [ ] **渠岸**：岸石带单侧交替点景，距水轴 2 格，避桥带。

## 五、切片纪律（manifest-first 强化）

1. **新切片三查**（tools 侧自动化）：
   - 连通分量查残片：主分量外的贴边/大块次分量=邻件带入→按主分量 bbox±1px 重切（实测脚本见本轮 board_notice 等 4 例）；
   - 列剖面查"半件"：中缝非全透明=两件粘连→分切或收窗；
   - 贴边审查：内容紧贴窗边 <1px=疑似截断，对照源图人工复核。
2. **旋转派生**：90° 整数旋转像素无损（合规）；旋转后需查内容色带（画死的水纹会转到侧边）。
3. **尺寸纪律**：原生整窗+alpha 修边；禁拉伸禁重绘；车轿族 96px 高一律 0.5 半缩（_spawn_prop pscale）。
4. manifest 全量重跑才会更新数据库（单件模式只出 PNG）。
