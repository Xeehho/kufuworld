# 《江湖志》主线剧情设计文档（v1 评审稿）

> 文档定位：为现有游戏内容设计一条「量大管饱、不复杂、能玩通」的主线剧情。
> 核心原则：**每个剧情节点 = 一段对话 + 一个现有系统就能完成的目标**，尽量不新增玩法，只新增剧本与状态。

---

## 一、设计总纲

### 1.1 设计原则

1. **复用优先**：剧情目标全部绑定现有系统——任务/奇遇/誓约/门派/战斗/农场/合成/商店/建造，不发明新玩法。
2. **单线推进、分支结局**：主线只有一条（简单、不易卡关），但在关键节点根据「道德值/门派归属/经营数据」分叉出 4 个结局（量大管饱）。
3. **门槛宽松**：每幕只设 1~2 个数值门槛（声望/贡献），达不到时可通过随机悬赏任务补足，保证一定能玩通。

### 1.2 参考游戏与借鉴点

| 参考游戏 | 借鉴点 |
|---|---|
| 金庸群侠传 | 门派武侠世界观、正邪道德值、结局由道德决定 |
| 大侠立志传 | 低起点成长线：杂役小事做起 → 声望积累 → 卷入大事件 |
| 太吾绘卷 | 门派模拟（贡献/晋升/门派战）作为主线推动力 |
| 鬼谷八荒 | 奇遇填充旅途、突破门槛的节奏感 |
| 饥荒/星露谷 | 生存与经营（耕种/合成/建房）作为「归隐结局」的支撑 |

## 二、世界观与背景

### 2.1 江湖格局：一盟八派

三十年前正邪大战后，武林盟主之位空悬至今，江湖形成「一盟八派」格局（直接对应游戏内 8 个门派）：

| 立场 | 门派 | 现状 |
|---|---|---|
| 正派 | 少林寺 | 封山修佛不问世事，暗中看守封印法阵 |
| 正派 | 武当派 | 老掌门以身殉封印，青黄不接，隐忍待发 |
| 正派 | 峨眉派 | 女弟子为主，与武当交好，主和 |
| 正派 | 丐帮 | 弟子遍布市井，唯一消息灵通的门派 |
| 邪派 | 日月教 | 残部蛰伏黑木崖，新教主「夜无痕」图谋血月重生 |
| 邪派 | 五毒教 | 苗疆炼毒，与日月教狼狈为奸，负责血祭仪式 |
| 中立 | 华山派 | 剑宗气宗内斗刚平，实力大损，观望风向 |
| 中立 | 逍遥派 | 世外隐门，不问世事，暗中收藏封印秘法残页 |

### 2.2 核心冲突：血月之劫

- 三十年前，日月教教主「血手人屠」厉沧海被正道七派联手封印于南疆**白骨祭坛**之下（对应游戏内白骨祭坛营地）。
- 近年来封印松动：天上月现血晕，白骨祭坛昼夜渗血，蛇虫躁动、流民为匪（对应山贼营地）、各地怪事频出（对应 20 个随机奇遇）。
- 日月教新教主「夜无痕」集齐三样祭品（古墓残卷、地脉血髓、五毒血祭），即可引血月之力复活厉沧海，血洗中原。
- 主角身携一枚刻火焰纹的旧铜牌，是三十年前封印之战的遗物，也是唯一能**补全封印/夺取血月之力**的钥匙。

## 四、主线剧情（27 节点）

> 节点表字段说明：
> - **触发**：节点开启条件（S=剧情阶段变量）

### 需新增内容清单（全部为「剧本数据 + 轻量脚本」）
1. `GameManager.story_stage: int`（0~27 剧情进度变量）
