> **每次开发任务开始前必读本文档。** 汇总全项目历史踩坑（Phase A~H 全部阶段）+ 2026-08-27 前期验收轮新坑。
> 按主题分类，标 🔴=必踩必炸 / 🟡=条件触发 / 🔵=假错防误判。
> 详细全文见 `REFACTOR_STATUS.md`；每日新增记录见 `.trae/gameWork.md`（本地）。

## 一、资源与贴图管线 🔴

1. **【致命】运行时禁止调用 `generate_all()`**——内含 `generate_player_frames/generate_npc_frames`，会用程序画法覆盖 `sprites/player|npc` 的素材包帧！
   - 重生成瓦片一律走 `gen.generate_tiles()` 或 `tools/regen_tiles.gd`
   - `texture_generator.gd` 改完必须删对应 PNG 再重生成才生效（磁盘 PNG 是产物非源文件）
2. **运行时加载 PNG 必须走 `TextureGen.load_png_texture()`**——新 PNG 无 import 数据，`load()`/`ResourceLoader.exists()` 会失败（角色/瓦片隐形）。存在性检查用 `FileAccess.file_exists`，禁止 `ResourceLoader.exists`。
3. **管线权属**：terrain 五件套(grass/grass_dark/path/farmland/water)归 python 管线（`import_pack_assets.py`），生成器不写这五个；地形瓦片缺失时 push_warning 提示重跑 `python tools/import_pack_assets.py terrain`。
4. **素材包树表不是均匀 2x2 大格**：松 32x80(4x2)/橡 64x64(4x2)/竹 48x80(3x2)。新增树种前必须用连通分量分析实测（`tools/probe_tree_components.py`），声明 cell 跨树会画出半棵树。
5. **Pixel Crawler Body_A 的 Side 表原生朝右**（肤色质量探针判定）；left 帧必须显式镜像导出并按 `dirn="left"` 着装；导出前先清陈旧帧（`_clean_stale_player_frames`），否则旧程序画法残留混入运行时。
6. **NPC 导出必须逐帧处理**：整条 union-strip 重采样会因帧间透明间隔导致帧切片错位→PNG 损坏。按内容 bbox 归一化到目标高（当前 29px），脚底以本表 frame0 为基准锚定。
7. **TileSet 生成器顺序**：必须先 `ts.add_source(source, id)`，再对 TileData 设置碰撞多边形/y_sort——source 未加入 TileSet 前物理层感知不到（`physics.size()=0`），碰撞写入静默失败（曾导致河流无碰撞可涉水）。
8. **y_sort_origin 报错**：Godot 4 的 TileSet 无此属性，在 TileData 上设置。

## 二、场景与渲染层级 🟡

9. **实体层统一 z=2 + 递归 Y-sort**（Phase G 确立）：新实体挂 World 树时根节点 `z_index=2` 且 position 锚在脚底/墙脚（贴图用 offset 上移）；中间容器节点必须 `y_sort_enabled=true`，否则子项按容器 y=(0,0) 排序全员沉底。
10. **z0 装饰会被 TileMap 吞掉**：树影子精灵曾用相对 z-1（等效 z0）被完全盖住。凡往 World 挂 z0 的装饰注意层级（作物/浆果丛/站台均 z=2）。
11. **像素反推瓦片坐标**：先减中心偏移再除格宽 `round((px-8)/16)`，直接 `round(px/16)` 会在半格边界系统性偏移一格。
12. **大雾天气截图全屏土色**：视觉分析前先清 WeatherController + 还原 CanvasModulate。
13. **角色顶部消失**：Player/NPC z_index 低于瓦片所致（现已统一 2，特效层 fx8/指示器30/雨雪1000 不受影响）。

## 三、UI 与输入 🟡

14. **HUD 根节点必须 `set_anchors_and_offsets_preset(PRESET_FULL_RECT)`**（禁止 `set_anchors_preset`）：后者默认保留偏移，对 0 尺寸节点把偏移写成负父尺寸→根节点永远 0 尺寸、居中面板全部失效错位（曾致属性面板被遮挡，7 处统一改过）。
15. **面板子节点必须 add_child 到面板自身**，不能挂 HUD 根节点（曾致商店/死亡界面元素飞到左上角）。
16. **模态锁定单一来源 `player._is_ui_blocking()`**：新模态面板加入 "ui_modal" 组即可被识别；任务日志抽屉展开要单独查 `QuestLogHUD.expanded`（它不在 ui_modal 组）。
17. **project.godot 的 [input] 段覆盖内置动作的风险**：一旦定义了 `ui_left/right/up/down`，`ui_cancel` 等其他内置动作必须显式声明——动作轮询 `Input.is_action_just_pressed("ui_cancel")` 对注入时序敏感不可靠，**ESC 类退出逻辑优先用 `_unhandled_input` 事件驱动**（keycode 4194305），并 `set_input_as_handled()`。
18. **数字键按上下文分派，禁止全局拦截**：商店内选商品/奇遇面板选项/任务日志接取/建造选型/平时切工具；任务日志展开时玩家侧必须被锁定（事件消费不影响 `Input.is_action_just_pressed` 轮询，双通道会双触发）。
19. **鼠标悬停 UI 不触发攻击**：`_is_mouse_over_ui()`（gui_get_hovered_control）；TrackerHUD 卡片必须 MOUSE_FILTER_STOP 才能被识别。
20. **按钮焦点**：UITheme.style_button 已设 FOCUS_NONE——新建按钮若不经过 UITheme，空格/回车会误触聚焦按钮。
21. **节点路径**：ShopHUD/QuickMenu 等在 `/root/Main/World/UI/XXX`，不是 `/root/Main/XXX`。
22. **Godot 对重名子节点自动改名 "@Node2D@N"**：调试统计建筑数量用 `get_nodes_in_group("building_prop")`，勿按名字前缀统计。
23. **UI tween 子属性路径陷阱**：某面板 `tween_property(panel, "modulate.a", ...)` 报 property not found（同写法其他面板正常，原因未明）——稳妥写法是整色插值 `tween_property(panel, "modulate", Color(1,1,1,1), t)`。
24. **死亡触发玩家表现**：death_system 正确姿势是直接找 player 组节点调用方法，不要只靠 `player_died/player_respawned` 信号——`GameManager.take_hit` 内部首次 emit 必然早于 player 侧任何 connect（Main._ready 中途 await 使 deferred 提前冲刷）。

## 四、数据与逻辑 🟡

25. **ItemFactory.PHASE_C_ITEMS 必须收录一切掉落/合成物 id**，否则 `give()` 静默返回 false 不进背包（铁矿石/草药已与 inventory 默认物品对齐同 id 堆叠）。
26. **敌人营地锚定出生点**而非固定坐标；`find_nearest_reachable(max_r=40)` 可能把不可达锚点拉回出生区→营地成员立刻进仇恨圈。测试玩家行为前先把玩家传远（探针内置 +520,+520 位移）。
27. **weather_controller._process 每帧用 world_time 重算 current_hour**：想固定时段必须改 `wc.world_time = h*60*time_scale`（直接赋 current_hour 下一帧就被覆盖）。
28. **音效断言用 `audio_controller.history.has()`**，勿用 last_played（会被后续音效覆盖）。
29. **GDScript 语法坑**：三元式优先级低于 % 和算术——`"a % b if c else d"` 解析为 `"(a%b) if c else d"`；数组下标/Variant 返回值不能用 `:=` 推断类型（如 `get_item_count` 需显式 `: int`）。
30. **围合地形必须留门**：城镇栅栏圈十字方向、门派山环、洞穴南侧；新增围合地形后必须跑 `_ensure_connectivity()`（BFS 可达集→≥6 格 pocket 最近点对 L 形开路：水→桥17/阻挡→沙6）。
31. **孤岛扫描边界**：用 `Vector2(x,y).length() > WORLD_RADIUS-8` 过滤，否则边界沙带误判为 orphan。
32. **世界半径/河流数量变更**会连带影响安全出生点校验——出生点 `_relocate_player_to_safe_spawn()` 三级搜索（7x7+200连通→5x5+80→5x5兜底）+ 城镇选址避让 15 瓦片，改地图参数后跑一遍确认日志。

## 五、工具链与验证 🔵

33. **探针用完立即移除 project.godot 的 [autoload] 注入**（ProbeAutoload 等），每次跑完检查残留空行（CRLF 文件 `replace("\n")` 匹配不上 `\r\n`）。
34. **CLI 杀进程丢 stdout 缓冲**：探针一律文件日志（`tools/probe_log.txt` 系）；窗口模式(GUI子系统)连 stdout 都没有——runner 的 Popen stdout 必须落文件句柄而非 PIPE。
35. **godot_path.txt 是 GBK 编码且路径含中文目录**：bash 直接展开乱码，经 python subprocess 调用。
36. **`--check-only` 语法检查对引用 autoload 单例的脚本必报假错**（player.gd:DialogManager / survival_hud:GameManager 等 "Identifier not found"），只看真解析错。
37. **--script 独立 SceneTree 模式下 autoload 标识符不可见**，属假错。
38. **后台长命令（>60s）**：node child_process spawn detached + 输出重定向文件轮询；CLI 直接跑 godot 时重定向 `>` 在 PowerShell 下可能产生空文件——用 `python subprocess` capture。
39. **本机环境 user:// 落在项目根 `Godot/app_userdata`**（已加 .gitignore）；`.godot/` 编辑器缓存也已移出版本库。
40. **MCP godot 会话**：`editor_state` 空参会报错（传 session_id）；开两个 Trae 时 9500 端口被先启动者抢占——Godot 面板"已连接"不代表连的是当前窗口的 MCP，`session_manage(op="list")` 返回 0 会话即端口被抢，关另一窗口后 Reload Plugin。
41. **视觉审计纪律**：画面结论必须来自截图工具（`tools/run_shots.py` 9 机位）或探针采样，禁止凭空断言；**必须按验收标准逐项生成 checklist 核对（边距/间距/穿模分开打勾），禁止整体印象式扫图**（教训：任务日志"进行中的委托"行上下 4px 间距漏检，用户指出后复验修复）。
42. **审计谓词要对照烘焙 PNG 实测主色**，勿凭想象设阈值（湿润农田是压暗棕而非偏蓝）。
