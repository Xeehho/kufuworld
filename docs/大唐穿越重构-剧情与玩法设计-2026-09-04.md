# 《贞观行者》大唐穿越重构——剧情与玩法设计（v1 立项稿）

## 一、一句话概念

**《我在长安修大唐》式的历史经营 RPG**：白天是躬耕垄亩的农家子，夜里是点亮科技树的穿越者——
声望喂养系统，系统兑换神装，从陈家村一亩三分地，一路杀到渭水桥受降、白江口焚船，
最终在「自立为王 / 封王拜相 / 现代唐朝」三条终局中，给这个时代一个自己的答案。

**核心幻想（三根支柱）**：
1. **降维打击爽感**——现代常识（种痘、水泥、复式记账）在唐初都是神迹（对标《贞观大闲人》）。
2. **养成陪伴感**——拟人化系统「糖糖」随声望进化，全程嘴毒吐槽（对标网文系统流人格化趋势）。
3. **历史参与感**——亲历渭水之盟、阴山夜袭、白江口海战，站在真实史实的骨架上改写血肉（对标《唐砖》《大唐声望系统》）。

## 三、世界观与时代背景

### 3.1 穿越设定

- **主角**：陈拾安，22 岁，某二本院校历史系大二学生，在便利店勤工俭学。历史知识扎实（剧情预知合理化）、动手能力强（理工复现合理化）、爱看纪录片和网文（玩家代入合理化）。
- **死亡与穿越**：2026 年某夜班后，为推开一个冲上马路的孩子被货车撞击身亡。再睁眼，已是大唐**武德九年（626 年）秋**——玄武门之变刚过两个月、渭水之盟墨迹未干。
- **魂穿载体**：长安城外、灞桥以东**陈家村**同名农家子「陈拾安」（重病濒死被夺舍）。系统解释为「命格对齐、魂归同类」——同名设定省去改名尴尬，且保留农家出身（完美衔接现有农场系统）。
- **系统觉醒**：穿越当晚，一只巴掌大的青光雏鸟落在主角肩头，自称系统之灵**「糖糖」**（谐音「唐」）。

### 3.2 时代锚点：为什么是武德九年

选择这个时间点的原因（全是剧情富矿）：

1. **渭水之耻（626 年 8 月）刚发生**——颉利可汗兵临长安、太宗斩白马立盟贿退突厥，视为奇耻。主角穿越即身处「国耻余波」中，天然背负雪耻主线（北击线预热）。
2. **贞观之治元年将至**——跟着明君从谷底爬起，玩家全程参与盛世建造。
3. **贞观元年至二年关中大旱、蝗灾（史实）**——第一幕的天然危机剧本，主角的现代农业知识有了第一个舞台。

### 3.5 长安城·盛世图卷（本作第一奇观）

> 2026-09-04 拍板：**长安要大、要华丽**——酒肆、青楼等风月场所俱全，王府/世家/功臣等府邸体系全量入城（见 3.5.4），作为本作体量最大的可探索区域；**长安为独立场景地图**（见 3.5.1-4）。
> 本节只定「玩法与内容」；城市尺寸/坊数取舍/街区工程方案见**已立项的[《长安城地图设计MD》](长安城地图设计.md)**（2026-09-04 工程稿，全游戏先行核心工程）。

#### 3.5.1 设计目标

长安不是背景板，是本作的**第二主角**：

1. **尽可能大**：以史实 108 坊为蓝图按比例呈现（「百千家似围棋局，十二街如种菜畦」），全游戏最大地图；
2. **随剧情长大**：城市分三阶段扩建（见 3.5.5）——城市成长线与主角声望线**同构**，玩家每推进一幕，长安就繁华一分；
3. **处处可玩**：每个坊至少一个玩法钩子，拒绝贴图观光；
4. **独立场景地图（2026-09-04 拍板）**：长安**不嵌入**程序化开放世界，而是一张独立地图——从开放世界经城门/灞桥过场进出。收益：①不受开放世界 chunk 加载半径与地形生成算法约束，坊墙街巷可手工半手工精雕；②宵禁可做整城联动（暮鼓一响全城坊门齐闭）；③独立加载允许远高于开放世界的建筑密度与装饰量。具体工程方案归《长安城地图设计MD》。

#### 3.5.3 特色场所详设（酒肆·青楼）

**西市·胡姬酒肆「琥珀光」**

- 经营者：粟特胡商康老三（§8 西域胡商势力接口）合伙经营，主角二幕可入股（经营线）。
- 玩法钩子四合一：
  1. **情报集散地**——游侠儿的据点，悬赏/传闻刷新点（旧丐帮情报职能的落点）；
  2. **酒令小游戏**——投壶/骰盘/飞花令（飞花令=文名检定变体），赢酒令涨文名、套情报；
  3. **胡姬歌舞演出**——间歇演出事件，观赏恢复心情、触发际遇；
  4. **酿酒产业链**——工坊酿酒→酒肆销货；终局线解锁蒸馏烈酒（军用火药基底/医用消毒，一物两线）。
- 风味细节：三勒浆、郎官清等史实名酒入菜单；店名取「兰陵美酒郁金香」的琥珀光意象——后世诗入唐，恰好是「文心残卷」的元笑话：连酒肆招牌都是系统授权的。

**平康坊·青楼「天香阁」**

- 尺度红线：**风雅化处理**——全程歌舞、酒令、题诗、听曲，不涉及露骨内容（像素RPG尺度）。
- 台柱：花魁**柳拂衣**（琵琶大家，原创人物），阁中歌姬各擅诗词书画。
- 玩法钩子：
  1. **花魁斗诗会**（季度事件）：文名检定夺魁→花魁青眼→名物线索/政商情报；
  2. **听曲社交**：文人社交场，消费换文名经验与人脉；
  3. **崔明远强聘事件**（二幕 2-5 后续）：士族反派逼娶柳拂衣——主角介入三选一（赎身/文战/搬军门），民心+文名大涨，反派线深化；
  4. **赎身支线**：为柳拂衣赎身→她执掌长安情报网（游侠儿+青楼双网合并，枭雄线重要资产）。

> 酒肆/青楼均为**新场所类型**：复用建筑放置与 NPC 日程管线，功能上是「情报站+检定场+产业链出口」三合一。

## 四、系统设定：糖糖与天命

### 4.1 系统之灵「糖糖」

- **形态**：青光雏鸟，栖息主角肩头（世界内 Sprite，z_index 高于玩家）。
- **性格**：嘴毒、贪吃、爱记账——**以声望为食**。声望是它的口粮，也是系统一切产出的硬通货。
- **形态进化（系统等级可视化）**：

| 系统等级 | 总声望门槛 | 糖糖形态 | 解锁 |
|---|---|---|---|
| Lv1 唤醒 | 0 | 青光雏鸟（巴掌大） | 面板+仓界5格 |
| Lv2 启蒙 | 500 | 幼鸟（会说话增多） | 商城开张 |
| Lv3 成长 | 3000 | 少年青鸾（可骑乘飞行？暂缓） | 天命轮盘（抽奖） |
| Lv4 振翅 | 12000 | 成年青鸾 | 仓界20格+图纸类商品全解锁 |
| Lv5 涅槃 | 50000 | 凤凰虚影 | 终幕抉择干预权（隐藏结局钥匙） |

- **可见性铁律（2026-09-04 拍板）**：糖糖**全程仅主角可见**——它是契约者的心象投影，世人看不见、听不见。由此派生三条演出铁律：
  1. **任何 NPC 台词永不提及糖糖**；主角与糖糖对话时，旁人看到的只是他「对着空气自言自语」——前期被坊间当痴儿的喜剧点，后期成了「陈公又在沉思」的轶闻；
  2. **打开系统面板=主角「入定发呆」**（复用现有模态锁输入），队友视角是原地出神；
  3. **唯一感知留白**：药王一脉的隐门高人能模糊感到「你身上有股说不清的祥和气」（道家因果感应，永不点破）；以及隐藏结局 D 中，当年车祸现场的孩子曾在泪眼中瞥见一道青光——全天下第二双看见糖糖的眼睛。
- **演出职责**：系统提示不用干巴巴的弹窗——默认由糖糖头顶气泡吐槽播报（复用 NPC 名牌气泡管线）；重大奖励才弹正式面板。这是本作区别于普通系统流的**辨识度卖点**。

### 4.2 系统功能六件套

1. **天命面板**（V 键复用 CharacterSheet）：四轨声望 + 天命点 + 科技树进度 + 系统任务。
2. **天命商城**：天命点消费主入口（§6）。
3. **天命轮盘**（抽奖）：单抽 100 点 / 十连 900 点（§6.3）。
4. **系统任务**：糖糖发布的隐藏主线（「改变一个时代的命运」），不可拒绝、跨幕长线，奖励唯一性道具。
5. **仓界**（随身空间）：初始 5 格，扩容靠商城/抽奖，解决「穿越者仓库」幻想。
6. **回响**（死亡保护）：死亡不清档——扣天命点 + 当幕声望 -5%，原地/村落复活。复用现有 DeathHUD，文案 reskin 为「天道回响，命数未绝」。

## 五、声望体系（核心资源设计）

### 5.1 四轨声望

| 轨道 | 代表人群 | 典型获取 | 对应旧系统 |
|---|---|---|---|
| **民心** | 乡野百姓、灾民、工匠 | 赈灾施粥、平价售粮、修桥铺路、传授农技 | 道德值 + 悬赏任务 |
| **朝纲** | 皇帝、宰辅、御史 | 献策被采纳、办好皇差、朝堂论战获胜 | 门派贡献 → 势力功勋 |
| **军功** | 行伍将校、府兵 | 随军参赞、练兵、战场首功 | Mob 营地讨伐 + 新战争玩法 |
| **文名** | 士林、国子监、五姓七望 | 诗文（系统授权「文心残卷」）、算学、格物之辩 | 奇遇事件 + 对话检定 |

- 每轨 0~10000，段位：默默无闻 → 小有名气 → 声名鹊起 → 名动京师 → 国之柱石 → **青史留名**（满轨，结局条件之一）。
- **总声望 = 民心×1.0 + 朝纲×1.2 + 军功×1.2 + 文名×0.8**（朝堂与军功是政治舞台的硬通货）。
- 声望决定：糖糖等级（系统等级）、天命点产出速率、剧情舞台门槛（见 5.2）。

### 5.2 声望阶梯 = 剧情舞台（不可跳级）

| 总声望段位 | 解锁舞台 | 标志演出 |
|---|---|---|
| 默默无闻 | 陈家村、灞桥集 | 乡民口中的「陈家小子」 |
| 小有名气 | 万年县衙 | 县令召见、献曲辕犁 |
| 声名鹊起 | 长安城（西市/坊间） | 微服贵人夜访（帝王认主伏笔） |
| 名动京师 | 太极宫朝堂 | 当廷献策、士族打压事件开启 |
| 国之柱石 | 天可汗体系、十六卫 | 领兵符、白江口挂帅 |
| 青史留名 | 终幕抉择 | 史官旁白结算画面 |

### 5.3 声望的消耗与风险（防刷屏无聊）

- **大事件可透支声望**：关键剧情选择（如为民抗命、朝堂死谏）消耗某轨声望换取剧情推进——声望既是资源也是立场。
- **声望衰减**：每轨每周衰减 0.1%（「人走茶凉」），迫使玩家保持活跃。
- **透支红线**：任一轨道跌破 0 以下 → 对应势力敌对（民心负 = 义军声讨；朝纲负 = 下狱事件）。

## 十、结局设计（3+1）

### 10.1 结局 A：自立为王（枭雄线）

- **路线**：终幕选择「保太子遗孤/自立门户」→ 借登州-辽东根据地割据 → 与李唐五年战争（战争玩法终局试炼场）→ 高潮：潼关对峙的「单骑议和」或「攻破长安」双收束。
- **达成条件**：军功+民心双「国之柱石」；游侠/胡商/寒门变革派支持；至少一场对唐战役胜利。
- **尾声画卷**：新朝「华」开国，登基大典上糖糖化凤凰绕梁——「陛下，这次换你养我了。」
- **失败分支**：战败被俘 → 圈禁终老结局（不算坏结局，史书体悼词演出）。

### 10.2 结局 B：封王封地（纯臣线）

- **路线**：终幕选择「告发/中立护唐」→ 助太宗平稳渡过储位危机 → 以「再造海陆之功」破异姓不王祖制，封**「镇海王」，领登州-辽东封地自治**。
- **达成条件**：朝纲+军功双「国之柱石」且从未背刺任何势力；四轨综合声望全服第一档。
- **尾声画卷**：凌烟阁增绘第二十五人；封地内继续自由经营（**该结局后开启纯沙盒模式**——保住星露谷式长线游玩价值）。
- 这是对历史人物（李靖式功成身退）的致敬线，**推荐默认线**。

### 10.3 结局 C：现代唐朝（文明线）

- **路线**：不选边站，而是「挟科技以令诸侯」→ 向太宗摊牌全部科技树 → 君臣立约「虚君立宪·实业救国」→ 时间蒙太奇：蒸汽机（646）→ 电报（652）→ 铁路（658）→ **百年后长安：电力夜市、火车站、报馆**的现代都市画卷。
- **达成条件**：科技树解锁 ≥90%（含蒸汽机传世图纸）；文名+民心双满轨；三线战争中至少两线亲历。
- **尾声画卷**：现代长安火车站的站牌下，糖糖以凤凰真身落在雕像肩头——雕像铭文：「大唐文明纪元元年，自此纪之」。
- 本线是《58万人的唐朝生活》式的终极浪漫，开发量最大，作为**三周目目标**设计。

### 10.4 隐藏结局 D：归返 2026（彩蛋线）

- **达成条件**：糖糖 Lv5（总声望 50000）+ 序章 S3 选择「推开孩子」+ 终幕前系统任务全清。
- **内容**：糖糖真身揭晓——它是「当年那个孩子血脉中的一缕善念」，跨越 1400 年来偿还因果（呼应 §4.1 可见性铁律：车祸现场那孩子曾瞥见一道青光，全天下第二双看见糖糖的眼睛）。终幕选择「回家」→ 2026 病床上苏醒（车祸昏迷三个月）→ 一切如南柯一梦——**摊开手掌，掌心躺着一枚开元通宝**。
- 纯演出结局（无新玩法成本），负责泪点与口碑传播。

## 十三、立项决议（2026-09-04 全部拍板）

原六项待决问题已全部确认，按推荐案执行；本日新增三项决议一并生效：

1. **「匈奴」字样**：采用史实敌人——「北击突厥、东御倭寇」叙事，不加架空注脚。
2. **武曌（武媚）**：仅作掖庭远景彩蛋，不展开。
3. **文抄公伦理**：主角诗文全部走系统「文心残卷」授权（糖糖毒舌吐槽这层皮保留）。
4. **战争玩法 MVP**：按 §12-P4 边界执行——据点夺取+多目标关卡，不做即时大军团战。
5. **现代序章**：便利店室内场景按 10 分钟流程做。
6. **旧存档**：不做兼容，直接要求新开档（旧档清声望/门派数据）。
7. **糖糖可见性**：全程仅主角可见，演出铁律见 §4.1（NPC 永不提及/自言自语喜剧/入定模态/隐门模糊感知）。
8. **长安城规格**：按 §3.5 执行——尽可能大、尽可能华丽，含酒肆/青楼风月场所，城市随剧情三阶段扩建（+结局C工业形态）。
9. **地图事项分库**：城市尺寸/坊数取舍/街区工程方案归《长安城地图设计MD》（**已立项**：`docs/长安城地图设计.md`），本文档不下沉工程细节。
10. **长安独立地图**：长安城为独立场景地图，不嵌入程序化开放世界；城门/灞桥过场进出，坊门宵禁整城联动（§3.5.1-4）。
11. **府邸体系全量入城**：东宫/诸王府/公主府/五姓七望/功臣国公府/胡邸（§3.5.4）——史实有载按史实安置（魏王府·延康坊、长孙府·崇仁坊、房府·务本坊、魏府·永兴坊），考据无载者标「架空安置」。
12. **长安先行（开发次序总纲）**：长安外城是全游戏**先行核心工程**——先建成并让人物自由行走（地图MD M1 验收），内景（皇宫/酒肆/青楼/府邸，均相当于独立地图）待**整个外城完成后**再启动（M4~M5）；建模管线总结后复制到便利店等剩余场景（M6）。详见[《长安城地图设计MD》](长安城地图设计.md) §一。
