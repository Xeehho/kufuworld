# 长安 Godot 手拼工作台

这套工具用于在 Godot 2D 编辑器中手工选择、摆放和调整长安素材。放下的每一件素材都是独立 `Sprite2D` 节点，可保存、移动、镜像和撤销；不会烘焙成一张背景图。

## 第一次启用

1. 打开 Godot，进入“项目 → 项目设置 → 插件”。
2. 启用“长安手拼工作台”。插件路径为 `res://addons/changan_map_editor/plugin.cfg`。
3. 点击右侧“长安手拼”面板中的“打开长安手拼场景”。
4. 建议立刻使用“场景 → 另存为”，例如保存为 `res://scenes/changan_manual_layout.tscn`，不要直接覆盖空白模板。

本次没有自动修改 `project.godot`，因此不会覆盖当前编辑器或其他开发线的插件设置；只需在 Godot 中启用一次。

## 拼图操作

- 默认开启“只显示原生素材（推荐）”。此前像素颗粒不一致的 AI 补件会被隐藏；关闭筛选后才会出现“AI补件（像素风格待定）”分类。
- 从分类或搜索结果选择缩略图，工具会显示素材原始像素尺寸和占格尺寸。
- 开启“放置模式”，在 2D 视图左键放置；位置自动吸附到 16px 网格，缩放固定为原尺寸 `1:1`。
- 建筑和道具使用底边中心锚并进入 `YSortContent`；地面件使用左上角锚并进入 `ManualGround`；前景件进入 `ManualForeground`。
- 按 `Esc` 退出放置模式后，可使用 Godot 自带选择和移动工具微调节点。
- “镜像所选”“所选对齐16px”“删除所选”都进入 Godot 撤销历史，可用 `Ctrl+Z` 恢复。
- 右键删除模式开启后，在素材上点击右键可快速删除。
- 参考底图是 168×142 格的长安道路/分区导引，可随时隐藏；它只用于对位，不会替代正式地面。

## 像素一致性纪律

- 优先使用“原生素材”筛选，不要混入 AI 补件，除非之后单独重绘到相同像素密度。
- 不使用任意缩放和旋转。工具放置时强制 `scale=(1,1)`、最近邻过滤；需要更大建筑时选大规格原生件，而不是拉伸小图。
- 建筑节点原点在脚底，沿街排布时先对齐底边，再比较屋脊高度。
- 主街、门洞、桥面至少留出既定通行宽度；碰撞和运行时导入在手拼版定稿后统一生成。

## 当前交付边界

本阶段解决“你可以在 Godot 里自己拼”的编辑体验和可保存场景。手拼场景尚未替换正式运行时长安；等你完成一个街区样板后，再从节点元数据生成建筑碰撞、Y-sort 验收和运行时布局数据。
