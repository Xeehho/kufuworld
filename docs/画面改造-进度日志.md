## 关键事实速查（已核实，避免重复调查）

- 瓦片 16×16；TileSet 每次启动由 `tileset_generator.build_tileset()` 内存重建，不读 .tres
- `generate_tiles()` 只在 PNG 缺失时生成 → **改生成逻辑后必须删 `sprites/tiles/` 对应 PNG**
- 树已不是瓦片：是 `tree_prop` 组的 Sprite2D 节点（自带椭圆阴影），树影方案按节点做
- 瓦片 ID 表以 tileset_generator.gd 实际注册表为准；**45-63 已被画面改造 P1 占用**（45-54 地面变体/55-63 碎屑装饰），后续新瓦片从 64 起
- 运行时 PNG 一律走 `TextureGen.load_png_texture()`；存在性判断用 `FileAccess.file_exists`
- TileSet：先 `add_source` 再写 TileData，否则碰撞/变体写入静默失败
- 素材包根：`downloaded_assets/Pixel Crawler - Free Pack/`，GDScript 侧经 `TextureGen._pack_image(rel)` 读取
- 机位截图：`python tools/run_w8_shots.py`（14 机位，覆盖 docs/shots/w8_*.png，约 2 分钟）
- 改造前基线截图：`docs/shots/before_p1/`（14 张，P1 前的状态）
- 全量回归：`python tools/regress_world.py`（102 断言）
- 素材分析工具（P1 新增，后续 Phase 复用）：`tools/analyze_ground_cells.py`（Floors 均匀格统计）、`tools/preview_veg_cells.py`（Vegetation 候选区放大图）
