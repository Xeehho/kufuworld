## 关键事实速查（已核实，避免重复调查）

- 瓦片 16×16；TileSet 每次启动由 `tileset_generator.build_tileset()` 内存重建，不读 .tres
- `generate_tiles()` 只在 PNG 缺失时生成 → **改生成逻辑后必须删 `sprites/tiles/` 对应 PNG**
- 树已不是瓦片：是 `tree_prop` 组的 Sprite2D 节点（自带椭圆阴影+tree_shadow组日照调节）
- 瓦片 ID 表以 tileset_generator.gd 实际注册表为准；**45-63 已被画面改造 P1 占用**，后续新瓦片从 64 起
- **阴影体系（P2 建成）**：`TextureGen.get_shadow_texture()` 共享 48x20 白椭圆 + `make_shadow_sprite(width, alpha)`
  工厂；player(24px/y+14)/npc(20px/y+1)/mob(22px/y+1)/station(26px/y+4)/建筑/树全部接入；
  `tree_shadow` 组由 weather_controller._tick_tree_shadows 每 0.5s 按日照因子缩放 alpha
- **P2.4 AO 教训**：连续整行暗边→16px 周期条纹（草坪成割纹/沙滩成砖块）；已改像素哈希 dash 断线（底缘2/3压暗0.90+顶缘1/4提亮1.05）
- 运行时 PNG 一律走 `TextureGen.load_png_texture()`；存在性判断用 `FileAccess.file_exists`
- TileSet：先 `add_source` 再写 TileData，否则碰撞/变体写入静默失败
- 素材包根：`downloaded_assets/Pixel Crawler - Free Pack/`，GDScript 侧经 `TextureGen._pack_image(rel)` 读取
- 机位截图：`python tools/run_w8_shots.py`（14 机位，覆盖 docs/shots/w8_*.png，约 2 分钟；probe 会强制 CanvasModulate=白，
  所以时段色调不在截图里体现）
- 改造前基线截图：`docs/shots/before_p1/`（P1 前状态）；P2 前状态即 P1 提交版（git 700cec5..168cf3e 后）
- 全量回归：`python tools/regress_world.py`（102 断言）
