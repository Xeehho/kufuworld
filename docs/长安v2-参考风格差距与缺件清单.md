# 长安 v2 参考风格差距与缺件清单

更新时间：2026-09-12

## 参考图提取出的目标语言

参考图只作为构图、密度和空间层次目标，不复刻其矿场题材、文字编号或具体建筑。长安需要借用的是：

1. **连续边界**：墙体、台地、水岸不是零散装饰，而是能把前景、中景、后景切开的连续结构。
2. **高差节点**：台阶、门洞、桥和坡道承担层级转换，玩家一眼能读出“从哪里上、从哪里下”。
3. **功能组团**：市铺与摊位、货车、货物形成商业组；住宅与院门、后院、生活杂物形成居住组；寺观与塔、殿、园树形成礼制组。
4. **连续街面**：临街屋檐尽量接续，窄巷和门前缓冲穿插其中，避免单栋建筑均匀撒点。
5. **边角有生活**：货箱、坛罐、布告、座椅、灯、车船填充墙脚和路缘；道路中心、门洞和桥面仍保持可走。

## 2026-09-12 已落地的现有素材方案

- 普通民居由自带一圈地坪的“邮票式院落件”改为原生单栋模块的南北两排连续屋檐，中间保留两格作业巷并布低矮生活件。
- 小型官署、非整院贵戚坊收紧为三开间连续街面，形成后署—内巷—前署的纵深。
- 两市中央由六个等距摊位改为半尺度牛车、三摊、小轿和两侧店排组成的物流带；车辆有实体脚印碰撞，NPC 点位避让车辆。
- 曲江形成上池—石桥—下池的水面序列，并补第二艘船、岸摊和座椅。
- 结构统计：291 个材质件、122 个接地阴影、97 个实体碰撞、27 个活动件、4 辆车、4 个水岸生活件、40 名 NPC；168×142、28 街区、四门和 BFS=0 保持不变。

## 缺件清单

### P0：决定能否达到参考图空间层次的硬缺口

| 缺件 | 最小完整套件 | 当前临时处理 | 限制 |
|---|---|---|---|
| 东西向原生外郭竖墙 | 西/东墙冠、墙身、墙脚、内外角、与横墙收口、门侧收口，各含 2~3 个重复变体 | 运行时只保留中性窄立面和碰撞环 | 不能用横墙旋转冒充；现状无法做出参考图那种有体量的左右围合 |
| 东西侧原生城门 | 向东/向西门楼、门洞、墙门过渡肩、门前台阶/坡道 | 开放关口＋原生正向守望楼、灯、石兽 | 接口和通行成立，但不像完整城门 |
| 台地/崖墙系统 | 台地顶面、四向立壁、凹凸角、上下端帽、四向台阶、栏杆/墙脚过渡 | 只用院墙、水岸和建筑体量制造弱层级 | 这是参考图“上下层城市”最关键的缺口；缺失时整城仍主要是同一海拔 |
| 模块化院墙转角 | 南北墙、东西墙、四角、月洞门、T 接、墙脚阴影 | 现有整院切件或 TileMap 单格院墙 | 整院件容易产生贴膜感，单格竖墙视觉体量不足 |
| 模块化建筑侧/背面 | 房屋左右侧墙、背墙、L/U 形屋脊转角、连廊、窄开间连接檐 | 只用正面建筑紧排、镜像和少量整院 | 能做连续南向街面，但很难围出参考图式不规则建筑群 |

### P1：把“结构成立”推到“繁华可信”的重要补件

| 缺件 | 建议内容 | 用途 |
|---|---|---|
| 唐风作坊外景 | 铁匠炉、木作台、染坊架、陶窑、粮栈装卸台，全部为室外视角 | 让官署/住宅/市集不再只靠店面区分功能 |
| 市井物流小件 | 麻袋、竹筐、木箱单件与 2~3 件簇、货担、拴马桩、窄货架 | 填墙脚和路缘；现有切件有少量箱桶，但缺统一语义和尺寸族 |
| 水岸完整套件 | 四向岸石、凹凸角、码头台阶、系船桩、护栏、窄木栈桥 | 曲江当前能成池，仍难做连续自然岸线和码头层级 |
| 烟火与动态装饰 | 炊烟/炉烟帧、旗幡轻摆、灯火帧、水面涟漪 | 参考图的活力有一部分来自动效；应单独挂节点，不烘进大背景 |
| 屋顶高度变体 | 同一色系的一层、二层、角楼、短檐连接件 | 打破同高屋檐，形成参考图式天际线起伏 |

## 进件规格

- 透明 PNG；16px 纹理网格，48px 组装模数；只允许整数像素定位，不拉伸。
- 每件标出视觉底边、建议 foot、是否可穿行、前景遮挡范围和配套转角。
- 竖墙/侧门必须原生绘制方向，禁止把正面素材旋转 90°。
- 同一套墙至少提供直段、两端帽、四角和门侧收口；只有直段不能进入最终围合验收。
- 入库先登记 manifest，再生成 prefab/碰撞；不得把整张参考图作为不可交互背景铺入场景。

## 后续实施顺序

1. 继续用现有件完成朱雀街沿线的连续前店后院和两市外围物流节点。
2. 用现有院墙/宫墙把皇城与官署的“院落序列”做完整，但不伪造竖向外郭墙。
3. 收到 P0 台地或竖墙套件后，先做一个 20×20 街区纵切，验证转角、台阶、碰撞、Y-sort，再扩全城。
4. 最终逐机位检查连续边界、道路净宽、人物前后遮挡、贴墙滑动、门洞和桥面通行。
