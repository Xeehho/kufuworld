## 一、闭环五步（谁干什么）

1. **你**：从源图裁散件 → 按 13 类丢进 `素材库/` 对应文件夹
2. **AI**：进件断言（§四）→ 按文件夹类别打语义 tag 入 manifest → 更新 Tiled 切片表
3. **你**：在 Tiled 每 kind 手拼 1 个样板段（从对应文件夹取件，含 11_街饰过渡 的过渡件）
4. **AI**：解析样板段 → 固化街区模板 → **同 kind 其余坊用你的模板单元做镜像/变体轮换铺设**（结构不随机、细节随机；import_qc 管反单调）→ 渲染图发你
5. **你拍板** → AI 导入 Godot → 探针 + 样张 + vision 四查（kind_qc 按类别带出规则）

> 工作量关键：28 坊只需手拼 13 个 kind 的样板段（共享件大量复用），其余由模板单元铺设。

## 三、裁剪须知（给用户的硬规矩）

1. **只从透明底 PNG 源表裁**——从参考图/截图/JPG 裁的件带底色，进件断言直接退回。
2. **切线对齐 16px 网格**：平铺件（地面/墙面/院墙段）长宽都是 16 的倍数；建筑件宽度=16 的倍数（对齐 foot 占格），高度自由但**同排建筑画布同高**（建议 92~96px，防脚线参差）。
3. **建筑底边贴画布底边**（底边锚定），檐子上方透明留白保留（檐宽≈foot 占格宽，防越墙压邻）。
4. 命名随意（中英均可，文件夹已给类别），同款变体 `_a/_b/_c` 后缀。
5. 拿不准切多大：先丢进来，AI 断言结果会告诉你差多少（进件是迭代的，不是一次到位）。

## 四、AI 进件断言（每次你丢图后跑）

| 断言 | 查什么 |
|---|---|
| 尺寸合规 | 平铺件 16 倍数；建筑件宽 16 倍数 |
| 底边锚 | 建筑件最底行非全透明（贴底），顶部允许透明 |
| 背景干净 | 四角/边缘像素透明（防从截图裁的带底色件） |
| 色板来源 | 与京城包色板比对（防串包/混入其他画风） |
| 同排同高 | 同文件夹内建筑件高度分组报告（不合规不退，只报告） |

不过关的件退回并标注原因；过关的入 manifest（带类别 tag），同步更新 Tiled 切片表。
