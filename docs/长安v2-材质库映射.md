## 一、闭环五步（谁干什么）

1. **你**：Tiled 打开 `素材库/<类别>/board.tmx` → 框选源表里的件盖章（件间距≥1 格）→ Ctrl+S
2. **AI**：板解析 → 连通域切件 → 不透明像素精裁 → 自动编号入 manifest（带类别 tag+源表溯源）→ 出一览图给你核对 → 更新 Tiled 切片表
3. **你**：在 Tiled 每 kind 手拼 1 个样板段（从对应类别的件里选，含 11_街饰过渡 的过渡件）
4. **AI**：解析样板段 → 固化街区模板 → **同 kind 其余坊用你的模板单元做镜像/变体轮换铺设**（结构不随机、细节随机；import_qc 管反单调）→ 渲染图发你
5. **你拍板** → AI 导入 Godot → 探针 + 样张 + vision 四查（kind_qc 按类别带出规则）

> 工作量关键：28 坊只需手拼 13 个 kind 的样板段（共享件大量复用），其余由模板单元铺设。

## 三、切件板规范（推荐进件形态，替代手动裁图）

每类一个 `素材库/<类别>/board.tmx`（`tools/gen_material_boards.py` 生成：16px 网格 / infinite / base64 单图层 pieces / 源表按 manifest category 预挂，外城板不挂内景表；2026-09-09 盖章渲染冒烟测试 PASS）：

1. Tiled 开板 → 图块面板选源表 → **框选一个件碰到的所有格子**盖章到板上
2. 件与件之间**至少留 1 格空白**（AI 按连通域切件；拿不准就多留）
3. **不用命名**：AI 自动编号（`<类别>_<序号>`）+ 一览图核对，样板段首次使用时再赋语义名
4. 精度原理：盖章只负责"圈定"（源表坐标级），AI 按**不透明像素**精裁边界——92px 高度等非 16 倍数情况自动处理；gid→源表区域精确对应，天然带 license 溯源（免色板串包疑虑）
5. 新材质包的表可在 Tiled 里自行追加（图块 16×16），进件解析按板内实际引用走
6. 血坑沿袭：磁盘改 tmx 后 Tiled 只重载不保存；勿动其他标签未保存的旧图

（备选）直丢 PNG 散件：只从透明底源图裁 / 切线对齐 16px 网格 / 建筑底边锚+同排同高——截图裁的带底色件直接退回。

## 四、AI 进件流程（每次你丢板/丢图后跑）

| 步骤 | 内容 |
|---|---|
| 板解析 | tmx 图层 chunks → gid（mask 翻转位）→ 源表+格位区域 |
| 切件 | 连通域分件 → 不透明像素裁边 → `<类别>_<序号>.png` |
| 断言（PNG 直投同查） | 尺寸合规（平铺件 16 倍数/建筑件宽 16 倍数）/ 底边锚（建筑件最底行非全透明）/ 背景干净（边缘透明）/ 同排同高报告 |
| 编目 | 入 manifest 带类别 tag+源表溯源 → 更新 Tiled 切片表 → 出一览图给你核对 |
