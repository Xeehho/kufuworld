## 一、出图前必读（全局纪律，每张图都适用）

1. **视角**：正交俯视（斜 45° 屋顶可，参考星露谷/京城包风格）——**禁止等距 3D、禁止透视畸变**。
2. **风格**：16-bit 像素风，与你的素材包同色系（暖砖红+灰瓦+木色）。建议把目标参考图和素材表截图一起喂给 AI 做风格锚定。
3. **画幅**：普通坊按 **1:1 方图**出（对应 320×320 画布）；合并坊（宫城/皇城 46×20 格）按**宽幅**出（≈2.3:1，裁到 736×320）。**禁止非整数缩放**。
4. **文字**：匾额/招牌/幌子一律**留白**——AI 写字必乱码，文字后期由管线贴片。
5. **构图优先**：宁可空一点，不要塞满——密度按各坊说明来（市场最密、皇宫最疏）。
6. **每坊一个主焦点**（landmark）+ 1~2 个次焦点，别所有建筑一样重要。
7. **过渡带**：建筑与街道之间要有一级垫层（院墙/台阶/绿化/矮墙），别让房子直接怼在路上——这是消灭"拼接感"的第一功臣。
8. **建筑朝向**：门面朝最近的主街（各坊"边界面"有说明）。

### 3.1 宫城·太极宫 `gongcheng`（0,2)+(0,3) 合并｜宽幅 736×320｜kind=palace

- **剧情衔接**：2-6 认主、朝堂事件、终幕摊牌的主舞台；凯旋动线终点（朱雀大街北上→承天门献俘）；朱雀大街北端正对承天门。
- **边界面**：南缘临横街（承天门楼压南面正中）；东西缘临主干纵街；北缘环城街。
- **要素清单**：承天门楼（最高规格，五门道意象）/ 太极殿金殿（最大建筑，金顶红柱）/ 两仪殿 / 配殿廊庑 / 四角金亭 / 丹墀方砖广场 / 仪仗件（华表·香炉）/ 宫墙一圈。
- **构图规则**（kind_qc: 中轴通透·左右均衡·大前庭）：承天门→丹墀广场→太极殿→两仪殿严格南北一线；东西配殿绝对对称；**建筑密度最低、留白最大**（≈1/3 覆盖），庭院大而有气势。
- **视觉等级**：最高（金殿金顶，全城唯一）。
- **出图提示词**：

```
16-bit 像素风，正交俯视，唐代皇宫太极宫全景，宽幅构图。南面正中是最高规格的承天门城楼（五个门道），向北中轴线上依次是巨大的丹墀广场、金顶红柱的太极殿（全图最大最华丽的建筑）、两仪殿；东西两侧配殿与廊庑严格左右对称，宫院四角各一座金顶小亭；朱红色宫墙环绕一圈。建筑密度低、庭院开阔、庄重大气，暖金与朱红主色，青灰瓦顶。匾额招牌全部留白不画字。不要等距3D透视，不要文字。
```
