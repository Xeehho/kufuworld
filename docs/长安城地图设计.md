# 《贞观行者》长安城地图设计（v1 工程稿）

> 文档定位：长安城是**全游戏先行核心工程**——先把外城地图建出来、让人物在其中自由行走，再以内景系统跟进宫殿/酒肆/青楼/府邸（各自相当于独立地图），最后**总结长安建模管线，复制到便利店等剩余场景**。
> 上游文档：[大唐穿越重构-剧情与玩法设计-2026-09-04.md](大唐穿越重构-剧情与玩法设计-2026-09-04.md) §3.5（内容与钩子）/ §13 决议10/11。
> 日期：2026-09-04　｜　状态：工程立项稿

## 一、开发次序总纲（用户拍板）

```
长安城外城（本MD，先行）
   ├─ M1 全城骨架 → 人物自由行走（第一个验收里程碑）
   ├─ M2~M3 坊内容 + 阶段化 + 宵禁
   ├─ M4~M5 内景系统（皇宫/酒肆/青楼/府邸=独立子地图，外城完成后启动）
   └─ M6 建模管线总结 ──► 复制到剩余场景：便利店（现代序章）、汤泉宫、登州、战场…
```

三条铁律：

1. **外城优先于内景**：内景（皇宫/酒肆/青楼/府邸）等**整个长安外城完成后**再动工（用户拍板）；
2. **可走优先于华丽**：M1 先交灰盒可走版，华丽密度在 M2/M3 分批叠加；
3. **管线优先于单点**：所有内容按「块生成器+数据驱动+模板复用」生产，禁止手工散摆——这是 M6 能复制到便利店的前提。

## 二、总体架构：独立场景 + 三层结构

长安为**独立场景地图**（玩法 MD §3.5.1-4），不嵌入程序化开放世界。场景内部三层：

| 层 | 内容 | 技术 |
|---|---|---|
| L1 外城层 | 城墙、宫城皇城、108街区、街道水系、两市 | 运行时生成的双层 TileMap（地面+装饰）+ building_prop 组节点 |
| L2 坊层 | 坊墙坊门、坊内街巷、宅地、府邸门面 | 块生成器按 JSON 数据填充 |
| L3 内景层 | 宫殿/酒肆/青楼/府邸内部（独立小场景） | 门面门tile+Area2D传送门 → 独立 .tscn 房间（M4 起） |

### 2.1 与开放世界的关系

- 开放世界（现有 chunk 系统）中，长安以**外郭城墙轮廓+四门**的形式存在（替代现有青石城 footprint）；
- 玩家从明德门（南中门）/延兴门/开远门/玄武门等城门触发过场 → 载入长安独立场景；城内出口原路返回，回到开放世界对应城门外位置；
-灞桥在开放世界侧（城东），作为序章入京的演出锚点。

### 2.2 场景组织

```
ChangAn (Node2D) [changan_generator.gd]
├── TileMap（Layer0 地面 / Layer1 装饰）——按 4×4 分区分帧填充
├── Props (Node2D) —— 城门楼/坊门楼/角楼等大件 Sprite+StaticBody2D（building_prop 组）
├── Portals (Node2D) —— 城门过场 + 内景传送门 Area2D
├── NPCRoot (Node2D) —— 城内 NPC（复用 npc_spawner 的 city_npc_configs 模式）
└── Env（CanvasModulate 昼夜 / 音景节点）
```

## 三、尺寸与比例决策

### 3.1 史实基底

外郭城东西约 9721m、南北约 8651m；坊多为 500~660m 见方；朱雀大街宽约 150m；宫城皇城居北部正中；三渠（龙首/清明/永安）引水入城；街植槐（「槐衙」）。

### 3.2 推荐案：12×9 街区网格

以「白居易：十二街如种菜畦」为意象，游戏网格取 **12 列 × 9 排 = 108 个街区**：

| 参数 | 取值 | 说明 |
|---|---|---|
| 街区块（坊）尺寸 | 26×26 瓦片（含坊墙1圈） | ≈676m，贴近史实大坊 |
| 宫城皇城区 | 北部中央 4列×2排（8街区合并） | ≈2700×1480m |
| 东西两市 | 各占 1 街区（皇城西南/东南第一排外侧） | 26×26 围市墙 |
| 朱雀大街 | 宽 9 瓦片 | ≈234m，较史实150m夸张约50%——为气势与玩法留白；M0 可参数化调至 7 |
| 主干街（横/纵） | 宽 5 | ≈130m，贴史实大街 |
| 沿城墙环路 | 宽 4 | — |
| 坊内十字街 | 宽 3，曲巷宽 2 | — |
| **总尺寸（含城墙）** | **约 396×300 瓦片** | 宽：12×26+11×5+2×4+城墙余量；高：9×26+8×5+2×4+余量 |
| 比例尺 | 1 瓦片 ≈ 26m | 全图推演基准 |

> 备选案 A（全比例 1:1，~1620×1440 瓦片）：沉浸最大但生成/内存/步行耗时全部超标，**否决**；
> 备选案 B（精简 36 坊，~260×240）：成本最低但撑不起「108坊盛世」核心幻想，仅作为 M0 期间的压力测试下界。

### 3.3 体量预算

- 地面层 ~12 万 cell + 装饰层 ~7 万 cell（坊内填充率约 55%）；
- 分 4×4=16 个分区（每区约 99×75），分帧填充（每帧一区，2 秒内完成），载入时配 loading 演出（明德门入城画卷）；
- 玩家步行横穿全城 ≈ 65~80 秒（疾跑减半）——中后期提供「车马行」快行点（坊门/市门停靠，解锁后坊际瞬移）。

## 四、地图数据结构（数据驱动核心）

### 4.1 块（Block）JSON Schema

一切街区皆数据，生成器零硬编码（M6 复制管线的基础）：

```json
{
  "grid": {"cols": 12, "rows": 9, "block": [26, 26],
           "street": {"zhunque": 9, "main": 5, "ring": 4},
           "palace_zone": {"cols": [5, 8], "rows": [1, 2]},
           "markets": [{"col": 4, "row": 3, "name": "西市"}, {"col": 9, "row": 3, "name": "东市"}]},
  "blocks": [{
    "id": "ward_yankang", "col": 3, "row": 5, "name": "延康坊",
    "type": "ward", "gates": ["N", "S"],
    "stage_unlock": 0,                       // 0=草创即开 1=治世 2=极盛
    "fill": "residential_high",              // 程序化填充模板
    "lots": [{"kind": "mansion", "ref": "wei_wangfu", "at": [4, 6], "size": [10, 8]}],
    "interiors": ["wei_wangfu"],             // L3 传送门登记
    "npc_config": "yan_kang",                // 日程表引用
    "canals": true, "trees": "locust"        // 水渠/行道槐
  }]
}
```

### 4.2 城市三阶段（对齐玩法 MD §3.5.5）

| stage | 解锁范围 | 依据 |
|---|---|---|
| 0 贞观草创 | 宫皇区+两市+北部4排坊（功臣官署区）；南部坊门封闭、内部留白 | 史实：唐前期南城「率无居人第宅」，人烟集中在北半城 |
| 1 贞观治世 | 北部7排+曲江一带 | 大明宫营建中（634） |
| 2 天可汗极盛 | 全108坊+大雁塔 | 四幕末 |

阶段只改数据（`stage_unlock` 过滤），不改生成器——**同一存档内城市随剧情长大**。

### 4.3 剧情坊清单（M2 精雕对象，14+2 坊）

平康坊（天香阁）、崇仁坊（长孙府/礼会院）、务本坊（房府/国子监）、延康坊（魏王府）、胜业坊（吴王府）、宣阳坊（长乐公主府）、长寿坊（怀化郡王府/西市畔）、崇义坊（清河崔府）、宣义坊（范阳卢府）、昌乐坊（博陵崔府）、崇贤坊（兰陵萧府）、靖善坊（大兴善寺）、安义坊（晋王府）、亲仁坊（功臣府群入口）；+ 晋昌坊（大慈恩寺，极盛期）、弘福坊（弘福寺）。

其余坊走程序化填充模板（`residential_low/high`、`mixed`），保证「满到溢出」的密度感但不手工。

## 六、连通性、宵禁与寻路

1. **生成即校验**：坊门/市门/宫门构成唯一通行口。生成完成后跑 BFS 连通断言（复用开放世界 `_ensure_connectivity` 思路）：从明德门出发须可达全部已解锁坊内十字街中心；断言工具进 `tools/` 回归脚本（沿用 probe_mob_wall 的探针经验，写进陷阱备忘）。
2. **宵禁联动**：暮鼓（时辰系统）触发——全城坊门换闭门瓦片+挂碰撞，次晨坊鼓开门；主角夜行只能走大街（犯禁事件由玩法层接管）。坊门状态由 ChangAn 场景统一广播，避免逐门轮询。
3. **未解锁坊**：`stage_unlock` 未达成的坊直接闭门+坊内不填充（省 cell），城墙外无虚空。
4. **水系通行**：三渠全城段均为碰撞水；桥瓦片复用现有 17。
5. **快行点**（车马行）：坊门/市门停驻牌，M3 后随阶段解锁，选点瞬移（同坊规则校验宵禁）。

## 七、进出城与存档

- **过场管线**：开放世界城门 Area2D → 淡出 → 载入 ChangAn 场景（分帧生成/loading 画卷）→ 玩家落明德门内 → 淡入；出城反向。灞桥演出位在开放世界侧。
- **存档**：长安场景状态 = 生成种子（固定）+ `stage` + 坊门开关 + 内景动态物。重进场景按数据重建，**不落整图快照**（与开放世界 chunk 同哲学）。
- **安全落点**：每次传送落点做 3×3 可通行校验（复用出生点螺旋扫描逻辑的简化版）。
